# Unix Domain Sockets

Unix Domain Sockets (UDS, or AF_UNIX) are
a specialized Inter-Process Communication (IPC) mechanism used for high-performance, bidirectional data exchange between applications running on the same physical machine. 
Unlike TCP/UDP, which are designed for network communications using IP addresses and ports, UDS operates entirely within the operating system kernel, using file system paths as address endpoint

### **Key Differences: UDS vs. TCP/UDP**

| Feature             | Unix Domain Sockets (UDS)                               | TCP / UDP (Network Sockets)                       |
| ------------------- | ------------------------------------------------------- | ------------------------------------------------- |
| **Scope**           | Local only (same host)                                  | Local or remote (network)                         |
| **Addressing**      | File system path (e.g., `/tmp/app.sock`)                | IP address + port number                          |
| **Speed / Latency** | High speed, low latency (bypasses network stack)        | Slower (network stack overhead)                   |
| **Reliability**     | Reliable (when using `SOCK_STREAM` or `SOCK_SEQPACKET`) | TCP is reliable; UDP is not                       |
| **Security**        | Filesystem permissions (`chmod`, ownership)             | Packet filtering (firewall rules)                 |
| **Best Used For**   | Same‑host IPC (e.g., Nginx ↔ PHP‑FPM)                   | Network communication (e.g., client ↔ web server) |

UDS (Unix Domain Sockets - AF_UNIX)

    How they work:
         When two processes communicate via UDS, they use the filesystem to find each other, but the data is passed directly through the kernel, not through network hardware.
    Why they are faster: 
        They avoid unnecessary overhead like packet routing, checksum calculations, and network stack navigation.
    
    Types: UDS supports stream-oriented (similar to TCP: SOCK_STREAM) and datagram-oriented (similar to UDP: SOCK_DGRAM) communication.
