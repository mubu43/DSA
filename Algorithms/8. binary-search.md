# Binary Search Algorithm - Complete Guide

## Overview
**Binary Search** is a highly efficient search algorithm that works on sorted arrays by repeatedly dividing the search interval in half. It's one of the most fundamental algorithms in computer science.

## Key Properties
- **Time Complexity**: O(log n) - exponentially faster than linear search
- **Space Complexity**: O(1) iterative, O(log n) recursive (call stack)
- **Prerequisite**: Array must be **sorted**
- **Method**: Divide and conquer approach
- **Performance**: Extremely efficient for large datasets

## Core Algorithm Concept

### The Central Idea
```
1. Compare target with middle element
2. If equal → Found! Return index
3. If target < middle → Search left half
4. If target > middle → Search right half
5. Repeat until found or search space empty
```

### Why It Works
- **Sorted property**: Enables elimination of half the search space
- **Invariant**: Target (if present) is always within current search bounds
- **Logarithmic reduction**: Each step halves the remaining possibilities

## Algorithm Variants

### 1. Standard Binary Search

#### Iterative Implementation
```cpp
int binarySearch(arr, target):
    left = 0, right = n-1
    
    while left <= right:
        mid = left + (right - left) / 2    // Avoid overflow
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1                 // Search right half
        else:
            right = mid - 1                // Search left half
    
    return -1                              // Not found
```

#### Recursive Implementation
```cpp
int binarySearchRec(arr, target, left, right):
    if left > right:
        return -1                          // Base case: not found
    
    mid = left + (right - left) / 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binarySearchRec(arr, target, mid+1, right)
    else:
        return binarySearchRec(arr, target, left, mid-1)
```

### 2. Boundary Search Variants

#### Find First Occurrence (Lower Bound)
```cpp
int findFirst(arr, target):
    left = 0, right = n-1, result = -1
    
    while left <= right:
        mid = left + (right - left) / 2
        
        if arr[mid] == target:
            result = mid
            right = mid - 1               // Continue searching left
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return result
```

#### Find Last Occurrence (Upper Bound)
```cpp
int findLast(arr, target):
    left = 0, right = n-1, result = -1
    
    while left <= right:
        mid = left + (right - left) / 2
        
        if arr[mid] == target:
            result = mid
            left = mid + 1                // Continue searching right
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return result
```

## Step-by-Step Example

### Search for 23 in [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78]

```
Initial: left=0, right=10, array size=11

Iteration 1:
mid = 0 + (10-0)/2 = 5
arr[5] = 23 == target → FOUND at index 5!

Total iterations: 1
Linear search would need: 6 iterations
```

### Search for 67 in same array

```
Iteration 1: mid=5, arr[5]=23 < 67 → search right
left=6, right=10

Iteration 2: mid=8, arr[8]=56 < 67 → search right  
left=9, right=10

Iteration 3: mid=9, arr[9]=67 == target → FOUND at index 9!

Total iterations: 3
Linear search would need: 10 iterations
```

### Search for 99 (not present)

```

Iteration 2: mid=8, arr[8]=56 < 99 → search right
left=9, right=10

Iteration 3: mid=9, arr[9]=67 < 99 → search right
left=10, right=10

Iteration 4: mid=10, arr[10]=78 < 99 → search right
left=11, right=10 → left > right → NOT FOUND

Total iterations: 4
```

## Advanced Binary Search Applications

### 1. Search in Rotated Sorted Array
```
Original: [0,1,2,4,5,6,7]
Rotated:  [4,5,6,7,0,1,2]

Strategy: Determine which half is sorted, then decide which half to search
```

### 2. Find Peak Element
```
Array: [1,2,3,1]
Peak: Element greater than both neighbors
Strategy: Move toward the side with larger neighbor
```

### 3. Square Root using Binary Search
```
Find sqrt(8):
Search space: [1, 4] (since 8/2 = 4)
Check if mid*mid <= 8, adjust bounds accordingly
```

### 4. Find Insert Position
```
Array: [1,3,5,6], Insert 2
Find position where 2 should be inserted: index 1
Result: [1,2,3,5,6]
```

## Mathematical Analysis

### Time Complexity Proof
- **Each iteration**: Eliminates half the remaining elements
- **Search space reduction**: n → n/2 → n/4 → n/8 → ... → 1
- **Number of iterations**: log₂(n)
- **Therefore**: T(n) = O(log n)

### Comparison with Linear Search
| Array Size | Linear Search (worst) | Binary Search (worst) | Speedup |
|------------|----------------------|----------------------|---------|
| 10         | 10                   | 4                    | 2.5x    |
| 100        | 100                  | 7                    | 14x     |
| 1,000      | 1,000                | 10                   | 100x    |
| 1,000,000  | 1,000,000            | 20                   | 50,000x |

### Space Complexity
- **Iterative**: O(1) - only uses a few variables
- **Recursive**: O(log n) - call stack depth equals number of iterations

## Common Pitfalls and Solutions

### 🚨 Integer Overflow
```cpp
// WRONG - can overflow
mid = (left + right) / 2

// CORRECT - prevents overflow
mid = left + (right - left) / 2
```

### 🚨 Infinite Loops
```cpp
// WRONG - can cause infinite loop with duplicates
while left < right:
    mid = left + (right - left) / 2
    if arr[mid] <= target:
        left = mid        // Could set left = mid forever
    else:
        right = mid - 1

// CORRECT - ensure progress in each iteration
while left <= right:
    mid = left + (right - left) / 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        left = mid + 1    // Always make progress
    else:
        right = mid - 1   // Always make progress
```

### 🚨 Boundary Conditions
```cpp
// Consider edge cases:
- Empty array: []
- Single element: [x]
- Two elements: [x, y]
- Target smaller than all elements
- Target larger than all elements
- All elements equal
```

```cpp

    else:

```

### Template 3: Right Boundary
```cpp

        left = mid
    else:
        right = mid - 1
```

## When to Use Binary Search

### ✅ Use When:
- **Data is sorted** or can be sorted
- **Frequent searches** on same dataset
- **Large datasets** where O(log n) matters
- **Memory is limited** (O(1) space)
- **Predictable performance** needed

### ❌ Avoid When:
- **Data is unsorted** and sorting is expensive
- **Frequent insertions/deletions** (maintains sorted order)
- **Very small datasets** (linear search might be faster due to constants)
- **Data doesn't support random access** (linked lists)

## Quick Revision Points

### 🎯 Essential Concepts
1. **Prerequisite**: Array must be sorted
2. **Core operation**: Compare with middle, eliminate half
3. **Time complexity**: O(log n) - exponentially better than O(n)
4. **Space**: O(1) iterative, O(log n) recursive
5. **Boundary handling**: Critical for correctness

### 🧠 Memory Aids
- **"Divide and Conquer"**: Split problem in half each time
- **"Elimination Process"**: Remove impossible half
- **"Middle Ground"**: Always check middle first
- **"Logarithmic Magic"**: Doubles efficiency with each element added
- **"Sorted Assumption"**: Only works on sorted data

### 🔧 Debug Checklist
1. **Array sorted?** Verify input precondition
2. **Overflow handled?** Use `left + (right-left)/2`
3. **Boundaries correct?** Check `<=` vs `<` conditions
4. **Progress guaranteed?** Ensure `left` increases or `right` decreases
5. **Edge cases tested?** Empty, single, two elements

### ⚡ Performance Tips
- **Cache-friendly**: Good locality of reference for arrays
- **Predictable branching**: Modern CPUs handle well
- **Minimal operations**: Simple arithmetic only
- **Early termination**: Return immediately when found
