# 16. Shortest Path Tree using Topological Sort in DAG

## Overview
Implementation of **shortest path tree computation** in **Directed Acyclic Graphs (DAGs)** using topological sorting. This approach is more efficient than Dijkstra's algorithm for DAGs since vertices can be processed in topological order, ensuring optimal substructure.

## Key Concepts

### Directed Acyclic Graph (DAG)
- A directed graph with **no cycles**
- Vertices can be arranged in a **linear order** (topological sort)
- Critical for many algorithms including shortest paths, scheduling, and dependency resolution

### Topological Sort
- **Linear ordering** of vertices such that for every directed edge (u,v), vertex u appears before v
- Only possible in **acyclic graphs**
- Two main algorithms: **DFS-based** and **Kahn's algorithm** (BFS-based)

### Shortest Paths in DAGs
- Can use **topological sort** + **relaxation** for optimal efficiency
- Process vertices in topological order ensures each vertex is processed after all its predecessors
- **Time complexity**: O(V + E) - better than Dijkstra's O((V+E)logV)

## Algorithm Steps

### 1. Verify Acyclicity
- Use topological sort to detect cycles
- If cycle exists, shortest paths are undefined

### 2. Topological Sort
- **DFS Method**: Use recursion with finishing time ordering
- **Kahn's Method**: Use in-degree counting with queue

### 3. Shortest Path Computation
1. **Initialize**: Set distance to source as 0, others as infinity
2. **Process in Topological Order**: For each vertex u in topological order
3. **Relax Edges**: Update distances to all adjacent vertices
4. **Guarantee**: When processing vertex u, shortest path to u is already determined

## Implementation Highlights

### Topological Sort - DFS Method
```cpp
void dfsTopologicalSort(int vertex, vector<bool>& visited, stack<int>& topoStack) {
    visited[vertex] = true;
    
    for (auto& edge : adjacencyList[vertex]) {
        if (!visited[edge.to]) {
            dfsTopologicalSort(edge.to, visited, topoStack);
        }
    }
    
    topoStack.push(vertex);  // Add after visiting all descendants
}
```

### Topological Sort - Kahn's Algorithm
```cpp
vector<int> topologicalSortKahn() {
    vector<int> inDegree(numVertices, 0);
    
    // Calculate in-degrees
    for (auto& edge : allEdges) {
        inDegree[edge.to]++;
    }
    
    // Start with vertices having in-degree 0
    queue<int> zeroInDegreeQueue;
    for (int i = 0; i < numVertices; i++) {
        if (inDegree[i] == 0) {
            zeroInDegreeQueue.push(i);
        }
    }
    
    vector<int> topoOrder;
    while (!zeroInDegreeQueue.empty()) {
        int current = zeroInDegreeQueue.front();
        zeroInDegreeQueue.pop();
        topoOrder.push_back(current);
        
        // Reduce in-degree of adjacent vertices
        for (auto& edge : adjacencyList[current]) {
            inDegree[edge.to]--;
            if (inDegree[edge.to] == 0) {
                zeroInDegreeQueue.push(edge.to);
            }
        }
    }
    
    return topoOrder;
}
```

### Shortest Path with Topological Sort
```cpp
pair<vector<int>, vector<int>> shortestPathDAG(int source) {
    vector<int> topoOrder = topologicalSort();
    vector<int> distance(numVertices, INT_MAX);
    vector<int> predecessor(numVertices, -1);
    
    distance[source] = 0;
    
    // Process vertices in topological order
    for (int u : topoOrder) {
        if (distance[u] != INT_MAX) {
            for (auto& edge : adjacencyList[u]) {
                if (distance[u] + edge.weight < distance[edge.to]) {
                    distance[edge.to] = distance[u] + edge.weight;
                    predecessor[edge.to] = u;
                }
            }
        }
    }
    
    return {distance, predecessor};
}
```

## Topological Sort Methods Comparison

### DFS-Based Method
- **Approach**: Depth-first traversal with finishing time ordering
- **Implementation**: Recursive with stack for ordering
- **Advantages**: Natural implementation, good for sparse graphs
- **Output**: One valid topological order

### Kahn's Algorithm
- **Approach**: Remove vertices with in-degree 0 iteratively
- **Implementation**: Queue-based with in-degree counting
- **Advantages**: Iterative, good for cycle detection
- **Output**: One valid topological order
