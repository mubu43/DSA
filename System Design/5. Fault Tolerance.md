# Fault Tolerance in C++ Systems

## Introduction

Fault tolerance is the ability of a system to continue operating correctly even when components fail. In high-reliability systems, we assume that **failures will happen**—the question is how the system responds.

This document covers practical techniques for building C++ systems that detect, isolate, and recover from failures automatically, without human intervention.

## 1. Process Supervision

### What is Process Supervision?

A **supervisor** is a process (or thread) responsible for monitoring other processes and taking corrective action when they fail. This is the "let it crash" philosophy popularized by Erlang: instead of trying to handle every possible error, let faulty components crash and have a supervisor restart them.

```
┌─────────────────────────────────────────────────────────────────┐
│                      SUPERVISION TREE                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                       ┌─────────────┐                           │
│                       │ Root        │                           │
│                       │ Supervisor  │                           │
│                       └──────┬──────┘                           │
│                              │                                   │
│              ┌───────────────┼───────────────┐                  │
│              │               │               │                   │
│        ┌─────▼─────┐   ┌─────▼─────┐   ┌─────▼─────┐           │
│        │ Worker    │   │ Worker    │   │ Sub-      │           │
│        │ Process 1 │   │ Process 2 │   │ Supervisor│           │
│        └───────────┘   └───────────┘   └─────┬─────┘           │
│                                              │                   │
│                              ┌───────────────┼───────────────┐  │
│                              │               │               │  │
│                        ┌─────▼─────┐   ┌─────▼─────┐   ┌─────▼──┐
│                        │ Worker 3  │   │ Worker 4  │   │Worker 5│
│                        └───────────┘   └───────────┘   └────────┘
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Supervision Strategies

| Strategy | Description | Use Case |
|----------|-------------|----------|
| **One-for-One** | Restart only the failed child | Independent workers |
| **One-for-All** | Restart all children if one fails | Interdependent workers |
| **Rest-for-One** | Restart failed child and all after it | Sequential dependencies |
| **Simple-One-for-One** | Like one-for-one, but for dynamic children | Worker pools |

### Basic Process Supervisor Implementation

```cpp
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>
#include <signal.h>
#include <map>
#include <functional>
#include <string>
#include <vector>
#include <chrono>
#include <iostream>

class ProcessSupervisor {
public:
    enum class RestartStrategy {
        ONE_FOR_ONE,    // Restart only failed process
        ONE_FOR_ALL,    // Restart all if one fails
        REST_FOR_ONE    // Restart failed and all started after it
    };
    
    struct ChildSpec {
        std::string name;
        std::string executable;
        std::vector<std::string> args;
        int max_restarts = 5;
        std::chrono::seconds restart_window{60};
    };
    
private:
    struct ChildState {
        ChildSpec spec;
        pid_t pid = -1;
        std::vector<std::chrono::steady_clock::time_point> restart_times;
        bool permanent = true;
    };
    
    std::map<std::string, ChildState> children_;
    std::map<pid_t, std::string> pid_to_name_;
    RestartStrategy strategy_ = RestartStrategy::ONE_FOR_ONE;
    std::atomic<bool> running_{true};
    
public:
    void set_strategy(RestartStrategy strategy) {
        strategy_ = strategy;
    }
    
    bool add_child(const ChildSpec& spec) {
        if (children_.count(spec.name)) {
            return false;  // Already exists
        }
        
        ChildState state;
        state.spec = spec;
        children_[spec.name] = state;
        
        return start_child(spec.name);
    }
    
    void run() {
        // Set up signal handler for SIGCHLD
        signal(SIGCHLD, SIG_DFL);  // Use default (we'll wait explicitly)
        
        while (running_) {
            int status;
            pid_t pid = waitpid(-1, &status, WNOHANG);
            
            if (pid > 0) {
                handle_child_exit(pid, status);
            } else {
                // No child exited, sleep briefly
                std::this_thread::sleep_for(std::chrono::milliseconds(100));
            }
        }
    }
    
    void stop() {
        running_ = false;
        
        // Terminate all children
        for (auto& [name, state] : children_) {
            if (state.pid > 0) {
                kill(state.pid, SIGTERM);
            }
        }
        
        // Wait for termination
        std::this_thread::sleep_for(std::chrono::seconds(1));
        
        // Force kill any remaining
        for (auto& [name, state] : children_) {
            if (state.pid > 0) {
                kill(state.pid, SIGKILL);
                waitpid(state.pid, nullptr, 0);
            }
        }
    }
    
private:
    bool start_child(const std::string& name) {
        auto& state = children_[name];
        const auto& spec = state.spec;
        
        pid_t pid = fork();
        
        if (pid < 0) {
            std::cerr << "Fork failed for " << name << std::endl;
            return false;
        }
        
        if (pid == 0) {
            // Child process
            std::vector<char*> argv;
            argv.push_back(const_cast<char*>(spec.executable.c_str()));
            for (const auto& arg : spec.args) {
                argv.push_back(const_cast<char*>(arg.c_str()));
            }
            argv.push_back(nullptr);
            
            execv(spec.executable.c_str(), argv.data());
            
            // If exec fails
            std::cerr << "Exec failed for " << name << std::endl;
            _exit(1);
        }
        
        // Parent process
        state.pid = pid;
        pid_to_name_[pid] = name;
        
        std::cout << "Started child " << name << " with PID " << pid << std::endl;
        return true;
    }
    
    void handle_child_exit(pid_t pid, int status) {
        auto it = pid_to_name_.find(pid);
        if (it == pid_to_name_.end()) {
            return;  // Unknown child
        }
        
        std::string name = it->second;
        pid_to_name_.erase(it);
        
        auto& state = children_[name];
        state.pid = -1;
        
        int exit_code = WIFEXITED(status) ? WEXITSTATUS(status) : -1;
        bool signaled = WIFSIGNALED(status);
        int signal_num = signaled ? WTERMSIG(status) : 0;
        
        std::cout << "Child " << name << " exited"
                  << (signaled ? " by signal " + std::to_string(signal_num) 
                               : " with code " + std::to_string(exit_code))
                  << std::endl;
        
        // Apply restart strategy
        switch (strategy_) {
            case RestartStrategy::ONE_FOR_ONE:
                maybe_restart_child(name);
                break;
                
            case RestartStrategy::ONE_FOR_ALL:
                restart_all_children();
                break;
                
            case RestartStrategy::REST_FOR_ONE:
                restart_from(name);
                break;
        }
    }
    
    bool should_restart(ChildState& state) {
        auto now = std::chrono::steady_clock::now();
        auto& times = state.restart_times;
        
        // Remove old restart times outside the window
        auto cutoff = now - state.spec.restart_window;
        times.erase(
            std::remove_if(times.begin(), times.end(),
                          [cutoff](auto t) { return t < cutoff; }),
            times.end()
        );
        
        // Check if we've exceeded max restarts
        if (times.size() >= static_cast<size_t>(state.spec.max_restarts)) {
            std::cerr << "Child " << state.spec.name 
                      << " exceeded max restarts, giving up" << std::endl;
            return false;
        }
        
        times.push_back(now);
        return true;
    }
    
    void maybe_restart_child(const std::string& name) {
        auto& state = children_[name];
        
        if (should_restart(state)) {
            std::cout << "Restarting child " << name << std::endl;
            start_child(name);
        }
    }
    
    void restart_all_children() {
        // Stop all running children first
        for (auto& [name, state] : children_) {
            if (state.pid > 0) {
                kill(state.pid, SIGTERM);
            }
        }
        
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
        
        // Restart all
        for (auto& [name, state] : children_) {
            if (should_restart(state)) {
                start_child(name);
            }
        }
    }
    
    void restart_from(const std::string& failed_name) {
        bool found_failed = false;
        
        for (auto& [name, state] : children_) {
            if (name == failed_name) {
                found_failed = true;
            }
            
            if (found_failed) {
                if (state.pid > 0) {
                    kill(state.pid, SIGTERM);
                }
            }
        }
        
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
        
        found_failed = false;
        for (auto& [name, state] : children_) {
            if (name == failed_name) {
                found_failed = true;
            }
            
            if (found_failed && should_restart(state)) {
                start_child(name);
            }
        }
    }
};

// Usage
int main() {
    ProcessSupervisor supervisor;
    supervisor.set_strategy(ProcessSupervisor::RestartStrategy::ONE_FOR_ONE);
    
    supervisor.add_child({
        .name = "worker1",
        .executable = "/usr/local/bin/worker",
        .args = {"--id", "1"},
        .max_restarts = 5,
        .restart_window = std::chrono::seconds(60)
    });
    
    supervisor.add_child({
        .name = "worker2",
        .executable = "/usr/local/bin/worker",
        .args = {"--id", "2"},
        .max_restarts = 5,
        .restart_window = std::chrono::seconds(60)
    });
    
    supervisor.run();
    
    return 0;
}
```

### In-Process Thread Supervisor

For supervising threads within a single process:

```cpp
#include <thread>
#include <functional>
#include <map>
#include <mutex>
#include <condition_variable>
#include <atomic>
#include <chrono>
#include <iostream>

class ThreadSupervisor {
public:
    struct ThreadSpec {
        std::string name;
        std::function<void(std::atomic<bool>&)> work;  // Takes stop flag
        int max_restarts = 5;
        std::chrono::seconds restart_window{60};
    };
    
private:
    struct ThreadState {
        ThreadSpec spec;
        std::thread thread;
        std::atomic<bool> stop_flag{false};
        std::atomic<bool> running{false};
        std::vector<std::chrono::steady_clock::time_point> restart_times;
    };
    
    std::map<std::string, std::unique_ptr<ThreadState>> threads_;
    std::mutex mutex_;
    std::condition_variable cv_;
    std::atomic<bool> supervisor_running_{true};
    std::thread supervisor_thread_;
    
public:
    ThreadSupervisor() {
        supervisor_thread_ = std::thread([this] { supervisor_loop(); });
    }
    
    ~ThreadSupervisor() {
        stop();
    }
    
    void add_thread(const ThreadSpec& spec) {
        std::lock_guard<std::mutex> lock(mutex_);
        
        auto state = std::make_unique<ThreadState>();
        state->spec = spec;
        
        start_thread(*state);
        
        threads_[spec.name] = std::move(state);
    }
    
    void stop() {
        supervisor_running_ = false;
        cv_.notify_all();
        
        if (supervisor_thread_.joinable()) {
            supervisor_thread_.join();
        }
        
        std::lock_guard<std::mutex> lock(mutex_);
        for (auto& [name, state] : threads_) {
            state->stop_flag = true;
            if (state->thread.joinable()) {
                state->thread.join();
            }
        }
    }
    
private:
    void start_thread(ThreadState& state) {
        state.stop_flag = false;
        state.running = true;
        
        state.thread = std::thread([&state, this] {
            try {
                state.spec.work(state.stop_flag);
            } catch (const std::exception& e) {
                std::cerr << "Thread " << state.spec.name 
                          << " threw exception: " << e.what() << std::endl;
            } catch (...) {
                std::cerr << "Thread " << state.spec.name 
                          << " threw unknown exception" << std::endl;
            }
            state.running = false;
            cv_.notify_all();  // Wake up supervisor
        });
    }
    
    void supervisor_loop() {
        while (supervisor_running_) {
            std::unique_lock<std::mutex> lock(mutex_);
            
            // Wait for a thread to exit or timeout
            cv_.wait_for(lock, std::chrono::seconds(1));
            
            if (!supervisor_running_) break;
            
            // Check for dead threads
            for (auto& [name, state] : threads_) {
                if (!state->running && !state->stop_flag) {
                    // Thread died unexpectedly
                    if (state->thread.joinable()) {
                        state->thread.join();
                    }
                    
                    if (should_restart(*state)) {
                        std::cout << "Restarting thread " << name << std::endl;
                        start_thread(*state);
                    }
                }
            }
        }
    }
    
    bool should_restart(ThreadState& state) {
        auto now = std::chrono::steady_clock::now();
        auto& times = state.restart_times;
        
        auto cutoff = now - state.spec.restart_window;
        times.erase(
            std::remove_if(times.begin(), times.end(),
                          [cutoff](auto t) { return t < cutoff; }),
            times.end()
        );
        
        if (times.size() >= static_cast<size_t>(state.spec.max_restarts)) {
            std::cerr << "Thread " << state.spec.name 
                      << " exceeded max restarts" << std::endl;
            return false;
        }
        
        times.push_back(now);
        return true;
    }
};

// Usage
int main() {
    ThreadSupervisor supervisor;
    
    supervisor.add_thread({
        .name = "processor",
        .work = [](std::atomic<bool>& stop) {
            while (!stop) {
                // Do work
                std::this_thread::sleep_for(std::chrono::milliseconds(100));
                
                // Simulate occasional failure
                if (rand() % 1000 == 0) {
                    throw std::runtime_error("Random failure");
                }
            }
        },
        .max_restarts = 5,
        .restart_window = std::chrono::seconds(60)
    });
    
    // Run for a while
    std::this_thread::sleep_for(std::chrono::minutes(5));
    
    supervisor.stop();
    
    return 0;
}
```

## 2. Watchdogs

### What is a Watchdog?

A **watchdog** is a mechanism that monitors whether a component is still functioning correctly. If the component stops "feeding" the watchdog (sending heartbeats), the watchdog takes corrective action.

```
┌─────────────────────────────────────────────────────────────────┐
│                      WATCHDOG MECHANISM                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────────┐    heartbeat    ┌──────────────┐              │
│  │              │ ───────────────►│              │              │
│  │   Worker     │                 │   Watchdog   │              │
│  │   Thread     │                 │   Thread     │              │
│  │              │◄───────────────│              │              │
│  └──────────────┘   action if     └──────────────┘              │
│        │            timeout              │                       │
│        │                                 │                       │
│        ▼                                 ▼                       │
│   Does actual work               Monitors heartbeats            │
│   Sends periodic heartbeat       Takes action on timeout        │
│                                  (restart, alert, failover)     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Types of Watchdogs

| Type | Level | Scope | Reset Action |
|------|-------|-------|--------------|
| **Hardware Watchdog** | Hardware | System | Reboot machine |
| **Kernel Watchdog** | Kernel | System | Panic/reboot |
| **Software Watchdog** | Application | Process/Thread | Restart component |

### Software Watchdog Implementation

```cpp
#include <chrono>
#include <atomic>
#include <thread>
#include <functional>
#include <mutex>
#include <map>
#include <iostream>

class Watchdog {
public:
    using TimeoutCallback = std::function<void(const std::string& name)>;
    
    struct WatchedEntity {
        std::string name;
        std::chrono::milliseconds timeout;
        TimeoutCallback on_timeout;
    };
    
private:
    struct EntityState {
        WatchedEntity config;
        std::atomic<std::chrono::steady_clock::time_point> last_heartbeat;
        std::atomic<bool> triggered{false};
    };
    
    std::map<std::string, std::unique_ptr<EntityState>> entities_;
    std::mutex mutex_;
    std::atomic<bool> running_{true};
    std::thread watchdog_thread_;
    
public:
    Watchdog() {
        watchdog_thread_ = std::thread([this] { watchdog_loop(); });
    }
    
    ~Watchdog() {
        running_ = false;
        if (watchdog_thread_.joinable()) {
            watchdog_thread_.join();
        }
    }
    
    // Register an entity to be watched
    void watch(const WatchedEntity& entity) {
        std::lock_guard<std::mutex> lock(mutex_);
        
        auto state = std::make_unique<EntityState>();
        state->config = entity;
        state->last_heartbeat.store(std::chrono::steady_clock::now());
        
        entities_[entity.name] = std::move(state);
        
        std::cout << "Watchdog: Now watching " << entity.name 
                  << " with timeout " << entity.timeout.count() << "ms" << std::endl;
    }
    
    // Called by watched entity to indicate it's still alive
    void heartbeat(const std::string& name) {
        std::lock_guard<std::mutex> lock(mutex_);
        
        auto it = entities_.find(name);
        if (it != entities_.end()) {
            it->second->last_heartbeat.store(std::chrono::steady_clock::now());
            it->second->triggered.store(false);  // Reset trigger
        }
    }
    
    // Unregister an entity
    void unwatch(const std::string& name) {
        std::lock_guard<std::mutex> lock(mutex_);
        entities_.erase(name);
    }
    
private:
    void watchdog_loop() {
        while (running_) {
            auto now = std::chrono::steady_clock::now();
            
            {
                std::lock_guard<std::mutex> lock(mutex_);
                
                for (auto& [name, state] : entities_) {
                    auto last = state->last_heartbeat.load();
                    auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
                        now - last);
                    
                    if (elapsed > state->config.timeout && !state->triggered.load()) {
                        state->triggered.store(true);
                        
                        std::cerr << "Watchdog: " << name << " timed out after "
                                  << elapsed.count() << "ms" << std::endl;
                        
                        // Call timeout handler (outside lock would be better in production)
                        if (state->config.on_timeout) {
                            state->config.on_timeout(name);
                        }
                    }
                }
            }
            
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
        }
    }
};

// RAII wrapper for automatic heartbeats
class WatchdogScope {
    Watchdog& watchdog_;
    std::string name_;
    std::atomic<bool> running_{true};
    std::thread heartbeat_thread_;
    std::chrono::milliseconds interval_;
    
public:
    WatchdogScope(Watchdog& wd, const std::string& name,
                  std::chrono::milliseconds timeout,
                  Watchdog::TimeoutCallback on_timeout)
        : watchdog_(wd)
        , name_(name)
        , interval_(timeout / 3)  // Heartbeat 3x per timeout period
    {
        watchdog_.watch({name, timeout, std::move(on_timeout)});
        
        heartbeat_thread_ = std::thread([this] {
            while (running_) {
                watchdog_.heartbeat(name_);
                std::this_thread::sleep_for(interval_);
            }
        });
    }
    
    ~WatchdogScope() {
        running_ = false;
        if (heartbeat_thread_.joinable()) {
            heartbeat_thread_.join();
        }
        watchdog_.unwatch(name_);
    }
    
    // Manual heartbeat for operations that might take longer
    void kick() {
        watchdog_.heartbeat(name_);
    }
};

// Usage
Watchdog global_watchdog;

void worker_function() {
    WatchdogScope scope(global_watchdog, "worker_1",
                        std::chrono::seconds(5),
                        [](const std::string& name) {
                            std::cerr << "ALERT: " << name << " is stuck!" << std::endl;
                            // Could restart thread, send alert, etc.
                        });
    
    while (running) {
        // Normal work
        process_item();
        
        // If we're about to do something slow, kick the watchdog
        scope.kick();
        do_slow_operation();
    }
}
```

### Hardware Watchdog Integration (Linux)

On Linux, you can use the hardware watchdog:

```cpp
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/watchdog.h>

class HardwareWatchdog {
    int fd_ = -1;
    int timeout_seconds_;
    
public:
    explicit HardwareWatchdog(int timeout_seconds = 60) 
        : timeout_seconds_(timeout_seconds) 
    {
        fd_ = open("/dev/watchdog", O_WRONLY);
        if (fd_ < 0) {
            throw std::runtime_error("Failed to open /dev/watchdog");
        }
        
        // Set timeout
        if (ioctl(fd_, WDIOC_SETTIMEOUT, &timeout_seconds_) < 0) {
            close(fd_);
            throw std::runtime_error("Failed to set watchdog timeout");
        }
        
        std::cout << "Hardware watchdog enabled with " 
                  << timeout_seconds_ << "s timeout" << std::endl;
    }
    
    ~HardwareWatchdog() {
        if (fd_ >= 0) {
            // Write 'V' to disable watchdog on clean shutdown
            write(fd_, "V", 1);
            close(fd_);
        }
    }
    
    void kick() {
        if (fd_ >= 0) {
            ioctl(fd_, WDIOC_KEEPALIVE, nullptr);
        }
    }
};

// Usage - must kick regularly or machine reboots!
HardwareWatchdog hw_watchdog(30);

void main_loop() {
    while (running) {
        hw_watchdog.kick();
        
        do_work();
        
        std::this_thread::sleep_for(std::chrono::seconds(10));
    }
}
```

### Watchdog Patterns

#### Pattern 1: Deadline Watchdog

For operations that must complete within a deadline:

```cpp
class DeadlineWatchdog {
public:
    template<typename Func>
    static auto run_with_deadline(
        std::chrono::milliseconds deadline,
        Func&& func,
        std::function<void()> on_timeout = nullptr)
    {
        using ReturnType = std::invoke_result_t<Func>;
        
        std::promise<ReturnType> promise;
        auto future = promise.get_future();
        
        std::thread worker([&promise, &func]() {
            try {
                if constexpr (std::is_void_v<ReturnType>) {
                    func();
                    promise.set_value();
                } else {
                    promise.set_value(func());
                }
            } catch (...) {
                promise.set_exception(std::current_exception());
            }
        });
        
        auto status = future.wait_for(deadline);
        
        if (status == std::future_status::timeout) {
            // Timeout occurred
            if (on_timeout) {
                on_timeout();
            }
            
            // Note: Can't really kill the thread safely in C++
            // In production, might need to mark thread as "zombie" and not join
            worker.detach();
            throw std::runtime_error("Operation timed out");
        }
        
        worker.join();
        return future.get();
    }
};

// Usage
try {
    auto result = DeadlineWatchdog::run_with_deadline(
        std::chrono::seconds(5),
        []() {
            // Potentially slow operation
            return fetch_data_from_external_service();
        },
        []() {
            std::cerr << "External service timeout!" << std::endl;
        }
    );
} catch (const std::runtime_error& e) {
    // Handle timeout
}
```

#### Pattern 2: Progress Watchdog

For long operations, track progress instead of just heartbeats:

```cpp
class ProgressWatchdog {
    std::atomic<size_t> current_progress_{0};
    std::atomic<size_t> expected_total_{0};
    std::atomic<std::chrono::steady_clock::time_point> last_progress_time_;
    std::chrono::milliseconds stall_timeout_;
    
    std::function<void()> on_stall_;
    std::atomic<bool> running_{true};
    std::thread monitor_thread_;
    
public:
    ProgressWatchdog(std::chrono::milliseconds stall_timeout,
                     std::function<void()> on_stall)
        : stall_timeout_(stall_timeout)
        , on_stall_(std::move(on_stall))
    {
        last_progress_time_.store(std::chrono::steady_clock::now());
        
        monitor_thread_ = std::thread([this] { monitor_loop(); });
    }
    
    ~ProgressWatchdog() {
        running_ = false;
        if (monitor_thread_.joinable()) {
            monitor_thread_.join();
        }
    }
    
    void start_operation(size_t total) {
        expected_total_.store(total);
        current_progress_.store(0);
        last_progress_time_.store(std::chrono::steady_clock::now());
    }
    
    void update_progress(size_t current) {
        size_t previous = current_progress_.exchange(current);
        if (current > previous) {
            last_progress_time_.store(std::chrono::steady_clock::now());
        }
    }
    
    void increment_progress(size_t delta = 1) {
        current_progress_.fetch_add(delta);
        last_progress_time_.store(std::chrono::steady_clock::now());
    }
    
private:
    void monitor_loop() {
        while (running_) {
            auto now = std::chrono::steady_clock::now();
            auto last = last_progress_time_.load();
            auto elapsed = now - last;
            
            if (elapsed > stall_timeout_) {
                size_t current = current_progress_.load();
                size_t total = expected_total_.load();
                
                std::cerr << "Progress stalled at " << current << "/" << total
                          << " for " << std::chrono::duration_cast<std::chrono::seconds>(elapsed).count()
                          << " seconds" << std::endl;
                
                if (on_stall_) {
                    on_stall_();
                }
            }
            
            std::this_thread::sleep_for(std::chrono::milliseconds(500));
        }
    }
};

// Usage
void process_large_dataset(const std::vector<Item>& items) {

            std::cerr << "Processing stalled! Sending alert..." << std::endl;
        }
    );

    for (size_t i = 0; i < items.size(); ++i) {
```

## 3. Self-Healing Threads

### What are Self-Healing Threads?

**Self-healing threads** automatically recover from errors without external intervention. They catch exceptions, reset their state, and continue operating.

```
┌─────────────────────────────────────────────────────────────────┐
│                   SELF-HEALING THREAD LIFECYCLE                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│      ┌──────────────────────────────────────────────────┐       │
│      │                                                   │       │
│      ▼                                                   │       │
│  ┌───────┐     ┌─────────┐     ┌───────┐     ┌───────┐  │       │
│  │ Init  │────►│  Work   │────►│ Error │────►│ Reset │──┘       │
│  └───────┘     └────┬────┘     └───────┘     └───────┘          │
│                     │                                            │
│                     │ (normal)                                   │
│                     ▼                                            │
│               ┌───────────┐                                      │
│               │ Complete  │                                      │
│               └───────────┘                                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Basic Self-Healing Thread

```cpp
#include <thread>
#include <atomic>
#include <functional>
#include <chrono>
#include <iostream>
#include <exception>

template<typename State>
class SelfHealingThread {
public:
    using WorkFunction = std::function<void(State&, std::atomic<bool>&)>;
    using InitFunction = std::function<State()>;
    using ErrorHandler = std::function<bool(const std::exception&, State&, int)>;
    
private:
    WorkFunction work_;
    InitFunction init_;
    ErrorHandler error_handler_;
    
    std::thread thread_;
    std::atomic<bool> stop_{false};
    std::atomic<bool> healthy_{false};
    std::atomic<int> error_count_{0};
    std::atomic<int> recovery_count_{0};
    
    int max_consecutive_errors_ = 5;
    std::chrono::milliseconds error_backoff_ = std::chrono::milliseconds(1000);
    
public:
    SelfHealingThread(
        WorkFunction work,
        InitFunction init = []() { return State{}; },
        ErrorHandler error_handler = nullptr)
        : work_(std::move(work))
        , init_(std::move(init))
        , error_handler_(std::move(error_handler))
    {}
    
    ~SelfHealingThread() {
        stop();
    }
    
    void start() {
        thread_ = std::thread([this] { run(); });
    }
    
    void stop() {
        stop_ = true;
        if (thread_.joinable()) {
            thread_.join();
        }
    }
    
    bool is_healthy() const { return healthy_.load(); }
    int get_error_count() const { return error_count_.load(); }
    int get_recovery_count() const { return recovery_count_.load(); }
    
private:
    void run() {
        int consecutive_errors = 0;
        
        while (!stop_) {
            try {
                // Initialize state
                State state = init_();
                healthy_ = true;
                consecutive_errors = 0;
                
                // Run work function
                work_(state, stop_);
                
            } catch (const std::exception& e) {
                healthy_ = false;
                error_count_.fetch_add(1);
                consecutive_errors++;
                
                std::cerr << "Self-healing thread caught exception: " << e.what()
                          << " (consecutive: " << consecutive_errors << ")" << std::endl;
                
                // Call error handler if provided
                bool should_continue = true;
                if (error_handler_) {
                    try {
                        State dummy{};
                        should_continue = error_handler_(e, dummy, consecutive_errors);
                    } catch (...) {
                        // Error handler itself failed
                    }
                }
                
                if (!should_continue || consecutive_errors >= max_consecutive_errors_) {
                    std::cerr << "Self-healing thread giving up after "
                              << consecutive_errors << " consecutive errors" << std::endl;
                    break;
                }
                
                // Backoff before retry
                auto backoff = error_backoff_ * consecutive_errors;
                std::this_thread::sleep_for(backoff);
                
                recovery_count_.fetch_add(1);
                std::cout << "Self-healing thread attempting recovery..." << std::endl;
                
            } catch (...) {
                healthy_ = false;
                error_count_.fetch_add(1);
                std::cerr << "Self-healing thread caught unknown exception" << std::endl;
                
                std::this_thread::sleep_for(error_backoff_);
            }
        }
    }
};

// Usage example: Database connection that reconnects on failure
struct DBConnection {
    std::unique_ptr<Connection> conn;
    std::string connection_string;
};

SelfHealingThread<DBConnection> db_worker(

        while (!stop) {
            auto query = get_next_query();
            auto result = state.conn->execute(query);  // Might throw
            process_result(result);
        }
    },
    
    // Init function - (re)establish connection

        state.conn = std::make_unique<Connection>(state.connection_string);
        state.conn->connect();
        std::cout << "Database connection established" << std::endl;
        return state;
    },
    
    // Error handler
    [](const std::exception& e, DBConnection& state, int consecutive) -> bool {

    }
```

### Self-Healing with State Checkpointing

For long-running operations, checkpoint state to enable resumption:

```cpp
template<typename State>
class CheckpointedSelfHealingThread {
public:
    using WorkFunction = std::function<void(State&, std::atomic<bool>&)>;
    using Checkpoint = std::function<std::string(const State&)>;
    using Restore = std::function<State(const std::string&)>;
    
private:
    WorkFunction work_;
    Checkpoint checkpoint_;
    Restore restore_;
    
    std::string checkpoint_file_;
    std::mutex checkpoint_mutex_;
    std::chrono::steady_clock::time_point last_checkpoint_;
    std::chrono::seconds checkpoint_interval_{30};
    
    std::thread thread_;
    std::atomic<bool> stop_{false};
    
public:
    CheckpointedSelfHealingThread(
        WorkFunction work,
        Checkpoint checkpoint,
        Restore restore,
        const std::string& checkpoint_file)
        : work_(std::move(work))
        , checkpoint_(std::move(checkpoint))
        , restore_(std::move(restore))
        , checkpoint_file_(checkpoint_file)
    {}
    
    void start() {
        thread_ = std::thread([this] { run(); });
    }
    
    void stop() {
        stop_ = true;
        if (thread_.joinable()) {
            thread_.join();
        }
    }
    
    // Call periodically from work function
    void maybe_checkpoint(const State& state) {
        auto now = std::chrono::steady_clock::now();
        if (now - last_checkpoint_ > checkpoint_interval_) {
            do_checkpoint(state);
            last_checkpoint_ = now;
        }
    }
    
private:
    void run() {
        while (!stop_) {
            try {
                State state = load_or_create_state();
                work_(state, stop_);
                
                // Clean completion - remove checkpoint
                remove_checkpoint();
                break;
                
            } catch (const std::exception& e) {
                std::cerr << "Error: " << e.what() << ", will resume from checkpoint" << std::endl;
                std::this_thread::sleep_for(std::chrono::seconds(1));
            }
        }
    }
    
    State load_or_create_state() {
        std::lock_guard<std::mutex> lock(checkpoint_mutex_);
        
        std::ifstream file(checkpoint_file_);
        if (file.good()) {
            std::string data((std::istreambuf_iterator<char>(file)),
                            std::istreambuf_iterator<char>());
            std::cout << "Restoring from checkpoint" << std::endl;
            return restore_(data);
        }
        
        return State{};  // Fresh start
    }
    
    void do_checkpoint(const State& state) {
        std::lock_guard<std::mutex> lock(checkpoint_mutex_);
        
        std::string data = checkpoint_(state);
        
        // Write atomically using temp file + rename
        std::string temp_file = checkpoint_file_ + ".tmp";
        std::ofstream file(temp_file);
        file << data;
        file.close();
        
        rename(temp_file.c_str(), checkpoint_file_.c_str());
    }
    
    void remove_checkpoint() {
        std::lock_guard<std::mutex> lock(checkpoint_mutex_);
        std::remove(checkpoint_file_.c_str());
    }
};

struct BatchJobState {

    // Restore
```

### Self-Healing Thread Pool

```cpp
class SelfHealingThreadPool {
    struct Worker {
        std::thread thread;
        std::atomic<bool> healthy{true};
        std::atomic<size_t> tasks_completed{0};
        std::atomic<size_t> tasks_failed{0};
    };
    
    std::vector<std::unique_ptr<Worker>> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex queue_mutex_;
    std::condition_variable queue_cv_;
    std::atomic<bool> stop_{false};
    
    std::thread monitor_thread_;
    
public:
    explicit SelfHealingThreadPool(size_t num_workers) {
        for (size_t i = 0; i < num_workers; ++i) {
            add_worker();
        }
        
        // Start health monitor
        monitor_thread_ = std::thread([this] { monitor_workers(); });
    }
    
    ~SelfHealingThreadPool() {
        stop_ = true;
        queue_cv_.notify_all();
        
        for (auto& w : workers_) {
            if (w->thread.joinable()) {
                w->thread.join();
            }
        }
        
        if (monitor_thread_.joinable()) {
            monitor_thread_.join();
        }
    }
    
    template<typename F>
    void submit(F&& task) {
        {
            std::lock_guard<std::mutex> lock(queue_mutex_);
            tasks_.push(std::forward<F>(task));
        }
        queue_cv_.notify_one();
    }
    
private:
    void add_worker() {
        auto worker = std::make_unique<Worker>();
        Worker* w = worker.get();
        
        worker->thread = std::thread([this, w] { worker_loop(w); });
        workers_.push_back(std::move(worker));
    }
    
    void worker_loop(Worker* worker) {
        while (!stop_) {
            std::function<void()> task;
            
            {
                std::unique_lock<std::mutex> lock(queue_mutex_);
                queue_cv_.wait(lock, [this] {
                    return stop_ || !tasks_.empty();
                });
                
                if (stop_ && tasks_.empty()) break;
                
                task = std::move(tasks_.front());
                tasks_.pop();
            }
            
            // Execute with exception handling
            try {
                worker->healthy = true;
                task();
                worker->tasks_completed++;
            } catch (const std::exception& e) {
                worker->tasks_failed++;
                std::cerr << "Task failed: " << e.what() << std::endl;
                
                // Could requeue the task here if desired
            } catch (...) {
                worker->tasks_failed++;
                std::cerr << "Task failed with unknown exception" << std::endl;
            }
        }
    }
    
    void monitor_workers() {
        while (!stop_) {
            std::this_thread::sleep_for(std::chrono::seconds(5));
            
            size_t healthy_count = 0;
            for (auto& w : workers_) {
                if (w->healthy) {
                    healthy_count++;
                }
            }
            
            std::cout << "Thread pool health: " << healthy_count 
                      << "/" << workers_.size() << " workers healthy" << std::endl;
            
            // Could add logic to replace unhealthy workers here
        }
    }
};
```

## 4. Circuit Breakers Inside a Process

### What is a Circuit Breaker?

A **circuit breaker** is a pattern that prevents a system from repeatedly attempting an operation that's likely to fail. It "opens" after detecting failures, allowing the system to fail fast instead of waiting for timeouts.

```
┌─────────────────────────────────────────────────────────────────┐
│                    CIRCUIT BREAKER STATES                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│    ┌─────────────────────────────────────────────────────┐      │
│    │                                                      │      │
│    │    ┌────────┐   failure   ┌────────┐                │      │
│    │    │        │ ──────────► │        │                │      │
│    │    │ CLOSED │             │  OPEN  │────────┐       │      │
│    │    │        │ ◄────────── │        │        │       │      │
│    │    └────────┘   success   └───┬────┘        │       │      │
│    │         │                     │             │       │      │
│    │         │                     │ timeout     │       │      │
│    │         │                     ▼             │       │      │
│    │         │              ┌──────────┐         │       │      │
│    │         │              │HALF-OPEN │         │       │      │
│    │         │              └────┬─────┘         │       │      │
│    │         │                   │               │       │      │
│    │         │      success      │   failure     │       │      │
│    │         └───────────────────┘───────────────┘       │      │
│    │                                                      │      │
│    └─────────────────────────────────────────────────────┘      │
│                                                                  │
│  CLOSED:    Allow requests through, monitor for failures        │
│  OPEN:      Fail immediately, don't attempt operation           │
│  HALF-OPEN: Allow one test request to check if problem fixed    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Advanced Circuit Breaker Implementation

```cpp
#include <atomic>
#include <chrono>
#include <functional>
#include <mutex>
#include <stdexcept>
#include <iostream>

class CircuitBreaker {
public:
    enum class State {
        CLOSED,
        OPEN,
        HALF_OPEN
    };
    
    struct Config {
        int failure_threshold = 5;          // Failures before opening
        int success_threshold = 3;          // Successes to close from half-open
        std::chrono::milliseconds timeout{30000};  // Time before half-open
        std::chrono::milliseconds slow_call_threshold{5000};  // What's "slow"
        double slow_call_rate_threshold = 0.5;  // 50% slow calls opens circuit
        int minimum_calls = 10;             // Min calls before evaluating
    };
    
    struct Metrics {
        std::atomic<int64_t> total_calls{0};
        std::atomic<int64_t> successful_calls{0};
        std::atomic<int64_t> failed_calls{0};
        std::atomic<int64_t> slow_calls{0};
        std::atomic<int64_t> rejected_calls{0};
        
        void reset() {
            total_calls = 0;
            successful_calls = 0;
            failed_calls = 0;
            slow_calls = 0;
        }
    };
    
private:
    Config config_;
    Metrics metrics_;
    
    std::atomic<State> state_{State::CLOSED};
    std::atomic<int> consecutive_failures_{0};
    std::atomic<int> consecutive_successes_{0};
    
    std::chrono::steady_clock::time_point last_failure_time_;
    std::mutex state_mutex_;
    
    std::function<void(State, State)> on_state_change_;
    
public:
    explicit CircuitBreaker(Config config = {}) : config_(std::move(config)) {}
    
    void set_state_change_callback(std::function<void(State, State)> callback) {
        on_state_change_ = std::move(callback);
    }
    
    template<typename Func, typename... Args>
    auto execute(Func&& func, Args&&... args) 
        -> decltype(func(std::forward<Args>(args)...)) 
    {
        if (!allow_request()) {
            metrics_.rejected_calls++;
            throw CircuitBreakerOpenException();
        }
        
        auto start = std::chrono::steady_clock::now();
        
        try {
            auto result = func(std::forward<Args>(args)...);
            
            auto duration = std::chrono::steady_clock::now() - start;
            record_success(duration);
            
            return result;
            
        } catch (...) {
            record_failure();
            throw;
        }
    }
    
    // For void functions
    template<typename Func>
    void execute_void(Func&& func) {
        if (!allow_request()) {
            metrics_.rejected_calls++;
            throw CircuitBreakerOpenException();
        }
        
        auto start = std::chrono::steady_clock::now();
        
        try {
            func();
            
            auto duration = std::chrono::steady_clock::now() - start;
            record_success(duration);
            
        } catch (...) {
            record_failure();
            throw;
        }
    }
    
    State get_state() const { return state_.load(); }
    const Metrics& get_metrics() const { return metrics_; }
    
    // Manual controls
    void force_open() { transition_to(State::OPEN); }
    void force_close() { transition_to(State::CLOSED); }
    void reset() {
        metrics_.reset();
        consecutive_failures_ = 0;
        consecutive_successes_ = 0;
        transition_to(State::CLOSED);
    }
    
    class CircuitBreakerOpenException : public std::runtime_error {
    public:
        CircuitBreakerOpenException() 
            : std::runtime_error("Circuit breaker is open") {}
    };
    
private:
    bool allow_request() {
        State current = state_.load();
        
        switch (current) {
            case State::CLOSED:
                return true;
                
            case State::OPEN: {
                std::lock_guard<std::mutex> lock(state_mutex_);
                auto now = std::chrono::steady_clock::now();
                
                if (now - last_failure_time_ >= config_.timeout) {
                    transition_to(State::HALF_OPEN);
                    return true;  // Allow test request
                }
                return false;
            }
            
            case State::HALF_OPEN:
                // Allow limited requests in half-open
                return true;
        }
        
        return false;
    }
    
    void record_success(std::chrono::nanoseconds duration) {
        metrics_.total_calls++;
        metrics_.successful_calls++;
        
        bool is_slow = duration >= config_.slow_call_threshold;
        if (is_slow) {
            metrics_.slow_calls++;
        }
        
        State current = state_.load();
        
        if (current == State::HALF_OPEN) {
            consecutive_successes_++;
            consecutive_failures_ = 0;
            
            if (consecutive_successes_ >= config_.success_threshold) {
                transition_to(State::CLOSED);
            }
        } else if (current == State::CLOSED) {
            consecutive_failures_ = 0;
            
            // Check slow call rate
            evaluate_slow_call_rate();
        }
    }
    
    void record_failure() {
        metrics_.total_calls++;
        metrics_.failed_calls++;
        
        consecutive_failures_++;
        consecutive_successes_ = 0;
        
        {
            std::lock_guard<std::mutex> lock(state_mutex_);
            last_failure_time_ = std::chrono::steady_clock::now();
        }
        
        State current = state_.load();
        
        if (current == State::HALF_OPEN) {
            // Single failure in half-open goes back to open
            transition_to(State::OPEN);
        } else if (current == State::CLOSED) {
            if (consecutive_failures_ >= config_.failure_threshold) {
                transition_to(State::OPEN);
            }
        }
    }
    
    void evaluate_slow_call_rate() {
        int64_t total = metrics_.total_calls.load();
        
        if (total < config_.minimum_calls) {
            return;  // Not enough data
        }
        
        int64_t slow = metrics_.slow_calls.load();
        double slow_rate = static_cast<double>(slow) / total;
        
        if (slow_rate >= config_.slow_call_rate_threshold) {
            std::cerr << "Circuit breaker: Slow call rate " 
                      << (slow_rate * 100) << "% exceeded threshold" << std::endl;
            transition_to(State::OPEN);
        }
    }
    
    void transition_to(State new_state) {
        State old_state = state_.exchange(new_state);
        
        if (old_state != new_state) {
            std::cout << "Circuit breaker: " << state_name(old_state)
                      << " -> " << state_name(new_state) << std::endl;
            
            if (new_state == State::CLOSED) {
                metrics_.reset();
            }
            
            if (on_state_change_) {
                on_state_change_(old_state, new_state);
            }
        }
    }
    
    static const char* state_name(State s) {
        switch (s) {
            case State::CLOSED: return "CLOSED";
            case State::OPEN: return "OPEN";
            case State::HALF_OPEN: return "HALF_OPEN";
        }
        return "UNKNOWN";
    }
};

// Usage
CircuitBreaker db_circuit({
    .failure_threshold = 5,
    .success_threshold = 3,
    .timeout = std::chrono::seconds(30),
    .slow_call_threshold = std::chrono::seconds(2)
});

db_circuit.set_state_change_callback([](auto old_state, auto new_state) {
    send_alert("Database circuit breaker: " + 
               std::string(state_name(old_state)) + " -> " + 
               std::string(state_name(new_state)));
});

std::optional<User> get_user(int user_id) {
    try {

        });
    } catch (const CircuitBreaker::CircuitBreakerOpenException&) {

}
```

```cpp
public:
    std::shared_ptr<CircuitBreaker> get_or_create(
        const std::string& name,
        CircuitBreaker::Config config = {}) 
    {
        std::lock_guard<std::mutex> lock(mutex_);
        
        auto it = breakers_.find(name);
        if (it != breakers_.end()) {
            return it->second;
        }
        
        auto breaker = std::make_shared<CircuitBreaker>(config);
        breakers_[name] = breaker;
        return breaker;
    }
    
    void print_status() const {
        std::lock_guard<std::mutex> lock(mutex_);
        
        std::cout << "Circuit Breaker Status:\n";
        std::cout << std::string(60, '-') << "\n";
        
        for (const auto& [name, breaker] : breakers_) {
            auto state = breaker->get_state();
            auto& metrics = breaker->get_metrics();
            
            std::cout << name << ": "
                      << state_name(state) << " | "
                      << "calls=" << metrics.total_calls << " "
                      << "success=" << metrics.successful_calls << " "
                      << "failed=" << metrics.failed_calls << " "
                      << "rejected=" << metrics.rejected_calls << "\n";
        }
    }
};
```

### Bulkhead Pattern with Circuit Breakers

Isolate failures using bulkheads (separate thread pools):

```cpp
class Bulkhead {
    std::string name_;
    size_t max_concurrent_;
    std::atomic<size_t> current_{0};
    
    std::atomic<uint64_t> accepted_{0};
    std::atomic<uint64_t> rejected_{0};
    
public:
    Bulkhead(std::string name, size_t max_concurrent)
        : name_(std::move(name)), max_concurrent_(max_concurrent) {}
    
    class Token {
        Bulkhead* bulkhead_;
        bool valid_;
        
    public:
        Token(Bulkhead* b, bool v) : bulkhead_(b), valid_(v) {}
        ~Token() { if (valid_) bulkhead_->release(); }
        Token(Token&& other) noexcept : bulkhead_(other.bulkhead_), valid_(other.valid_) {
            other.valid_ = false;
        }
        operator bool() const { return valid_; }
    };
    
    Token try_acquire() {
        size_t current = current_.load();
        while (current < max_concurrent_) {
            if (current_.compare_exchange_weak(current, current + 1)) {
                accepted_++;
                return Token(this, true);
            }
        }
        rejected_++;
        return Token(this, false);
    }
    
    void release() {
        current_.fetch_sub(1);
    }
    
    double rejection_rate() const {
        uint64_t total = accepted_ + rejected_;
        return total > 0 ? static_cast<double>(rejected_) / total : 0.0;
    }
};

// Combine bulkhead with circuit breaker
class ResilientService {
    CircuitBreaker circuit_;
    Bulkhead bulkhead_;
    
public:
    ResilientService(size_t max_concurrent)
        : bulkhead_("service", max_concurrent) {}
    
    template<typename Func>
    auto call(Func&& func) -> decltype(func()) {
        // First check bulkhead
        auto token = bulkhead_.try_acquire();
        if (!token) {
            throw std::runtime_error("Bulkhead full - too many concurrent calls");
        }
        
        // Then check circuit breaker
        return circuit_.execute(std::forward<Func>(func));
    }
};
```

## 5. Hot Restart / Rolling Upgrades

### What is Hot Restart?

**Hot restart** allows a process to restart (for updates or recovery) without dropping connections or losing in-flight requests. The new process takes over seamlessly from the old one.

```
┌─────────────────────────────────────────────────────────────────┐
│                      HOT RESTART SEQUENCE                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Time ──────────────────────────────────────────────────────►   │
│                                                                  │
│  Old Process:  [Running]───[Draining]───[Exit]                  │
│                     │           │                                │
│                     │   hand    │                                │
│                     │   off     │                                │
│                     ▼           ▼                                │
│  New Process:      [Start]───[Running]──────────────────►       │
│                                                                  │
│  Connections:  ════════════════════════════════════════════►    │
│                        (no interruption)                         │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Socket Handoff (File Descriptor Passing)

Pass listening sockets from old process to new:

```cpp
#include <sys/socket.h>
#include <sys/un.h>
#include <unistd.h>
#include <cstring>

// Send file descriptor over Unix socket
bool send_fd(int unix_sock, int fd_to_send) {
    struct msghdr msg = {};
    struct iovec iov[1];
    char buf[1] = {'F'};
    
    iov[0].iov_base = buf;
    iov[0].iov_len = 1;
    msg.msg_iov = iov;
    msg.msg_iovlen = 1;
    
    // Control message for the file descriptor
    char control[CMSG_SPACE(sizeof(int))];
    msg.msg_control = control;
    msg.msg_controllen = sizeof(control);
    
    struct cmsghdr* cmsg = CMSG_FIRSTHDR(&msg);
    cmsg->cmsg_level = SOL_SOCKET;
    cmsg->cmsg_type = SCM_RIGHTS;
    cmsg->cmsg_len = CMSG_LEN(sizeof(int));
    *reinterpret_cast<int*>(CMSG_DATA(cmsg)) = fd_to_send;
    
    return sendmsg(unix_sock, &msg, 0) > 0;
}

// Receive file descriptor over Unix socket
int receive_fd(int unix_sock) {
    struct msghdr msg = {};
    struct iovec iov[1];
    char buf[1];
    
    iov[0].iov_base = buf;
    iov[0].iov_len = 1;
    msg.msg_iov = iov;
    msg.msg_iovlen = 1;
    
    char control[CMSG_SPACE(sizeof(int))];
    msg.msg_control = control;
    msg.msg_controllen = sizeof(control);
    
    if (recvmsg(unix_sock, &msg, 0) <= 0) {
        return -1;
    }
    
    struct cmsghdr* cmsg = CMSG_FIRSTHDR(&msg);
    if (cmsg && cmsg->cmsg_level == SOL_SOCKET && cmsg->cmsg_type == SCM_RIGHTS) {
        return *reinterpret_cast<int*>(CMSG_DATA(cmsg));
    }
    
    return -1;
}
```

### Complete Hot Restart Manager

```cpp
#include <sys/socket.h>
#include <sys/un.h>
#include <sys/wait.h>
#include <unistd.h>
#include <signal.h>
#include <atomic>
#include <thread>
#include <vector>
#include <iostream>

class HotRestartManager {
    struct ListeningSocket {
        int fd;
        std::string address;
        int port;
    };
    
    std::vector<ListeningSocket> listening_sockets_;
    std::string control_socket_path_;
    std::atomic<bool> draining_{false};
    std::atomic<int> active_connections_{0};
    
    std::function<void()> on_drain_complete_;
    
public:
    explicit HotRestartManager(const std::string& control_path)
        : control_socket_path_(control_path) {}
    
    // Called by parent process
    void register_socket(int fd, const std::string& address, int port) {
        listening_sockets_.push_back({fd, address, port});
    }
    
    void connection_started() {
        active_connections_++;
    }
    
    void connection_ended() {
        int remaining = --active_connections_;
        
        if (draining_ && remaining == 0) {
            std::cout << "All connections drained, ready to exit" << std::endl;
            if (on_drain_complete_) {
                on_drain_complete_();
            }
        }
    }
    
    // Initiate hot restart - spawn new process and hand off
    pid_t initiate_restart(const char* new_executable) {
        // Create Unix socket pair for control communication
        int control_sockets[2];
        if (socketpair(AF_UNIX, SOCK_STREAM, 0, control_sockets) < 0) {
            throw std::runtime_error("Failed to create control socket pair");
        }
        
        pid_t pid = fork();
        
        if (pid < 0) {
            close(control_sockets[0]);
            close(control_sockets[1]);
            throw std::runtime_error("Fork failed");
        }
        
        if (pid == 0) {
            // Child process - will become new server
            close(control_sockets[0]);  // Close parent's end
            
            // Set environment variable with control socket fd
            setenv("HOT_RESTART_FD", std::to_string(control_sockets[1]).c_str(), 1);
            
            // Exec new binary
            execl(new_executable, new_executable, nullptr);
            _exit(1);
        }
        
        // Parent process - old server
        close(control_sockets[1]);  // Close child's end
        
        // Send listening sockets to new process
        for (const auto& sock : listening_sockets_) {
            if (!send_fd(control_sockets[0], sock.fd)) {
                std::cerr << "Failed to send socket fd" << std::endl;
            }
        }
        
        // Signal completion
        char done = 'D';
        write(control_sockets[0], &done, 1);
        close(control_sockets[0]);
        
        // Start draining
        start_drain();
        
        return pid;
    }
    
    // Called by new process on startup
    bool receive_sockets_from_parent() {
        const char* fd_str = getenv("HOT_RESTART_FD");
        if (!fd_str) {
            return false;  // Normal startup, not a hot restart
        }
        
        int control_fd = std::stoi(fd_str);
        
        // Receive sockets until 'D' (done) signal
        while (true) {
            fd_set fds;
            FD_ZERO(&fds);
            FD_SET(control_fd, &fds);
            
            struct timeval timeout = {5, 0};  // 5 second timeout
            
            if (select(control_fd + 1, &fds, nullptr, nullptr, &timeout) <= 0) {
                break;
            }
            
            // Check for done signal
            char buf;
            if (recv(control_fd, &buf, 1, MSG_PEEK) > 0 && buf == 'D') {
                recv(control_fd, &buf, 1, 0);  // Consume it
                break;
            }
            
            // Receive file descriptor
            int fd = receive_fd(control_fd);
            if (fd >= 0) {
                listening_sockets_.push_back({fd, "", 0});
                std::cout << "Received socket fd " << fd << " from parent" << std::endl;
            }
        }
        
        close(control_fd);
        return !listening_sockets_.empty();
    }
    
    const std::vector<ListeningSocket>& get_listening_sockets() const {
        return listening_sockets_;
    }
    
    bool is_draining() const { return draining_; }
    
    void set_drain_callback(std::function<void()> callback) {
        on_drain_complete_ = std::move(callback);
    }
    
private:
    void start_drain() {
        std::cout << "Starting drain, " << active_connections_ 
                  << " active connections" << std::endl;
        
        draining_ = true;
        
        // Stop accepting new connections on our copy of the sockets
        for (auto& sock : listening_sockets_) {
            shutdown(sock.fd, SHUT_RD);
        }
        
        if (active_connections_ == 0) {
            if (on_drain_complete_) {
                on_drain_complete_();
            }
        }
    }
};

// Example usage
class Server {
    HotRestartManager restart_manager_;
    int listen_fd_ = -1;
    std::atomic<bool> running_{true};
    
public:
    Server() : restart_manager_("/tmp/server.sock") {}
    
    void run() {
        // Check if this is a hot restart
        if (restart_manager_.receive_sockets_from_parent()) {
            std::cout << "Hot restart: received sockets from parent" << std::endl;
            // Use the inherited sockets
            auto& sockets = restart_manager_.get_listening_sockets();
            if (!sockets.empty()) {
                listen_fd_ = sockets[0].fd;
            }
        } else {
            // Normal startup - create new socket
            listen_fd_ = create_listening_socket(8080);
            restart_manager_.register_socket(listen_fd_, "0.0.0.0", 8080);
        }
        
        // Set up signal handler for restart
        signal(SIGUSR1, [](int) {
            // Trigger restart on SIGUSR1
            global_server->trigger_restart();
        });
        
        restart_manager_.set_drain_callback([this] {
            running_ = false;
        });
        
        // Main accept loop
        while (running_) {
            int client_fd = accept(listen_fd_, nullptr, nullptr);
            if (client_fd < 0) {
                if (errno == EINVAL) break;  // Socket shutdown
                continue;
            }
            
            if (restart_manager_.is_draining()) {
                // Don't accept new connections during drain
                close(client_fd);
                continue;
            }
            
            restart_manager_.connection_started();
            
            // Handle in thread (simplified)
            std::thread([this, client_fd] {
                handle_connection(client_fd);
                close(client_fd);
                restart_manager_.connection_ended();
            }).detach();
        }
        
        std::cout << "Server shutdown complete" << std::endl;
    }
    
    void trigger_restart() {
        restart_manager_.initiate_restart("/usr/local/bin/server");
    }
};
```

### Rolling Upgrades

For services with multiple instances, upgrade one at a time:

```cpp
class RollingUpgradeCoordinator {
    struct Instance {
        std::string id;
        std::string host;
        int port;
        std::string version;
        bool healthy = true;
    };
    
    std::vector<Instance> instances_;
    std::string target_version_;
    
    std::function<bool(const Instance&)> health_check_;
    std::function<bool(const Instance&, const std::string&)> upgrade_instance_;
    std::function<void(const Instance&)> remove_from_lb_;
    std::function<void(const Instance&)> add_to_lb_;
    
public:
    void set_health_check(std::function<bool(const Instance&)> fn) {
        health_check_ = std::move(fn);
    }
    
    void set_upgrade_action(std::function<bool(const Instance&, const std::string&)> fn) {
        upgrade_instance_ = std::move(fn);
    }
    
    void set_lb_actions(
        std::function<void(const Instance&)> remove,
        std::function<void(const Instance&)> add) 
    {
        remove_from_lb_ = std::move(remove);
        add_to_lb_ = std::move(add);
    }
    
    struct UpgradeResult {
        bool success;
        std::vector<std::string> failed_instances;
        std::chrono::seconds total_time;
    };
    
    UpgradeResult perform_rolling_upgrade(const std::string& new_version) {
        auto start = std::chrono::steady_clock::now();
        target_version_ = new_version;
        std::vector<std::string> failed;
        
        for (auto& instance : instances_) {
            if (instance.version == new_version) {
                std::cout << instance.id << " already at target version" << std::endl;
                continue;
            }
            
            std::cout << "Upgrading " << instance.id << " from " 
                      << instance.version << " to " << new_version << std::endl;
            
            bool success = upgrade_single_instance(instance, new_version);
            
            if (!success) {
                failed.push_back(instance.id);
                
                // Decide whether to continue or abort
                if (failed.size() > instances_.size() / 3) {
                    std::cerr << "Too many failures, aborting upgrade" << std::endl;
                    break;
                }
            }
        }
        
        auto end = std::chrono::steady_clock::now();
        auto duration = std::chrono::duration_cast<std::chrono::seconds>(end - start);
        
        return {
            .success = failed.empty(),
            .failed_instances = failed,
            .total_time = duration
        };
    }
    
private:
    bool upgrade_single_instance(Instance& instance, const std::string& version) {
        // Step 1: Remove from load balancer
        std::cout << "  Removing from load balancer..." << std::endl;
        remove_from_lb_(instance);
        
        // Step 2: Wait for in-flight requests to complete
        std::cout << "  Draining connections..." << std::endl;
        std::this_thread::sleep_for(std::chrono::seconds(10));
        
        // Step 3: Perform upgrade
        std::cout << "  Upgrading..." << std::endl;
        if (!upgrade_instance_(instance, version)) {
            std::cerr << "  Upgrade failed!" << std::endl;
            // Try to restore to LB anyway
            add_to_lb_(instance);
            return false;
        }
        
        // Step 4: Health check
        std::cout << "  Health checking..." << std::endl;
        int retries = 10;
        while (retries-- > 0) {
            if (health_check_(instance)) {
                instance.version = version;
                instance.healthy = true;
                break;
            }
            std::this_thread::sleep_for(std::chrono::seconds(2));
        }
        
        if (!instance.healthy) {
            std::cerr << "  Health check failed!" << std::endl;
            // Rollback would happen here in production
            return false;
        }
        
        // Step 5: Add back to load balancer
        std::cout << "  Adding back to load balancer..." << std::endl;
        add_to_lb_(instance);
        
        std::cout << "  Instance " << instance.id << " upgraded successfully" << std::endl;
        return true;
    }
};
```

### Graceful Shutdown with Deadline

```cpp
class GracefulShutdown {
    std::atomic<bool> shutting_down_{false};
    std::atomic<int> active_requests_{0};
    std::chrono::seconds drain_timeout_{30};
    
    std::mutex mutex_;
    std::condition_variable cv_;
    
public:
    void set_drain_timeout(std::chrono::seconds timeout) {
        drain_timeout_ = timeout;
    }
    
    class RequestScope {
        GracefulShutdown* shutdown_;
        bool accepted_;
        
    public:
        RequestScope(GracefulShutdown* s, bool accepted) 
            : shutdown_(s), accepted_(accepted) {}
        
        ~RequestScope() {
            if (accepted_) {
                shutdown_->request_complete();
            }
        }
        
        operator bool() const { return accepted_; }
    };
    
    RequestScope try_accept_request() {
        if (shutting_down_) {
            return RequestScope(this, false);
        }
        active_requests_++;
        return RequestScope(this, true);
    }
    
    void request_complete() {
        int remaining = --active_requests_;
        if (shutting_down_ && remaining == 0) {
            cv_.notify_all();
        }
    }
    
    bool shutdown(bool wait_for_drain = true) {
        shutting_down_ = true;
        std::cout << "Shutdown initiated, " << active_requests_ 
                  << " active requests" << std::endl;
        
        if (!wait_for_drain) {
            return true;
        }
        
        std::unique_lock<std::mutex> lock(mutex_);
        bool drained = cv_.wait_for(lock, drain_timeout_, [this] {
            return active_requests_ == 0;
        });
        
        if (drained) {
            std::cout << "All requests drained successfully" << std::endl;
        } else {
            std::cout << "Drain timeout, " << active_requests_ 
                      << " requests remaining" << std::endl;
        }
        
        return drained;
    }
    
    bool is_shutting_down() const { return shutting_down_; }
};

// Usage
GracefulShutdown shutdown_handler;

void handle_request(const Request& req) {
    auto scope = shutdown_handler.try_accept_request();
    if (!scope) {
        return send_503_response(req);  // Service unavailable
    }
    
    // Process request normally
    process(req);
}

void signal_handler(int sig) {
    if (sig == SIGTERM || sig == SIGINT) {
        bool clean = shutdown_handler.shutdown(true);
        exit(clean ? 0 : 1);
    }
}
```

## Summary

| Concept | Key Takeaway |
|---------|--------------|
| **Process Supervision** | Let it crash, then restart. Use supervision trees with restart strategies. |
| **Watchdogs** | Monitor liveness with heartbeats. Detect and act on stalls. |
| **Self-Healing Threads** | Catch exceptions, reset state, continue. Checkpoint for resumability. |
| **Circuit Breakers** | Fail fast when dependencies are unhealthy. Prevent cascade failures. |
| **Hot Restart** | Hand off sockets, drain connections, zero-downtime upgrades. |

### Fault Tolerance Checklist

1. **Supervision hierarchy**: Define who supervises what
2. **Restart strategies**: Choose appropriate strategy for each component
3. **Health checks**: Implement comprehensive health monitoring
4. **Watchdogs**: Add deadlines to all blocking operations
5. **Exception handling**: Catch, log, and recover appropriately
6. **Circuit breakers**: Protect against slow/failing dependencies
7. **Graceful shutdown**: Drain connections before exit
8. **Hot restart support**: For zero-downtime deployments
9. **State checkpointing**: For resumable operations
10. **Alerting**: Notify on circuit breaks, excessive restarts
