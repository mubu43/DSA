# 8. Undirected Graph Data Structure

## Overview
Implementation of an **undirected graph** data structure using **adjacency list representation**. This focuses purely on the data structure itself - how to store vertices, edges, and perform basic graph operations without complex algorithms.

## Key Concepts

### Undirected Graph
- A graph where **edges have no direction**
- If vertex A is connected to vertex B, then B is also connected to A
- **Symmetric relationship**: edge (u,v) is the same as edge (v,u)
- Each edge connects exactly two vertices

### Adjacency List Representation
- **Space efficient**: Only stores existing edges
- **Dynamic**: Easy to add/remove edges
- **Access time**: O(degree) to find all neighbors
- **Best for sparse graphs**: When edges << vertices²

## Data Structure Components

### Core Data Members
```cpp
class UndirectedGraph {
private:
    int numVertices;                          // Number of vertices
    std::vector<std::vector<int>> adjacencyList;  // Adjacency list storage
};
```

### Key Operations
- **addEdge(u, v)**: Add undirected edge between vertices u and v
- **removeEdge(u, v)**: Remove edge between vertices u and v  
- **hasEdge(u, v)**: Check if edge exists between vertices u and v
- **getNeighbors(v)**: Get all vertices connected to vertex v
- **getDegree(v)**: Get number of edges connected to vertex v

## Implementation Details

### Adding an Edge
```cpp
void addEdge(int vertex1, int vertex2) {
    // Add vertex2 to vertex1's adjacency list
    adjacencyList[vertex1].push_back(vertex2);
    
    // Add vertex1 to vertex2's adjacency list (undirected)
    adjacencyList[vertex2].push_back(vertex1);
}
```

### Checking Edge Existence
```cpp
bool hasEdge(int vertex1, int vertex2) const {
    return std::find(adjacencyList[vertex1].begin(), 
                    adjacencyList[vertex1].end(), 
                    vertex2) != adjacencyList[vertex1].end();
}
```

### Getting Neighbors
```cpp
std::vector<int> getNeighbors(int vertex) const {
    return adjacencyList[vertex];  // Return copy of adjacency list
}
```

## Memory Layout

### Adjacency List Structure
```
Graph with edges: 0-1, 0-2, 1-3, 2-3

Vertex 0: [1, 2]     ← Connected to vertices 1 and 2
Vertex 1: [0, 3]     ← Connected to vertices 0 and 3  
Vertex 2: [0, 3]     ← Connected to vertices 0 and 3
Vertex 3: [1, 2]     ← Connected to vertices 1 and 2
```

### Memory Complexity
- **Space**: O(V + E) where V = vertices, E = edges
- **Each edge stored twice**: Once in each vertex's adjacency list
- **Dynamic allocation**: Grows as edges are added

## Basic Graph Patterns

### 1. Complete Graph (K_n)
- **Every vertex connected to every other vertex**
- **Edges**: n(n-1)/2 for n vertices
- **All vertices have degree**: n-1

```
K4 (Complete graph with 4 vertices):
  0 ─────── 1
  │ ╲     ╱ │
  │   ╲ ╱   │
  │   ╱ ╲   │
  │ ╱     ╲ │
  2 ─────── 3
```

### 2. Star Graph
- **One central vertex connected to all others**
- **Center degree**: n-1
- **Other vertices degree**: 1

```
Star Graph with 5 vertices:
    1
    │
2 ─ 0 ─ 3
    │
    4
```

### 3. Path Graph
- **Vertices connected in a line**
- **End vertices degree**: 1
- **Middle vertices degree**: 2

```
Path Graph:
0 ─ 1 ─ 2 ─ 3 ─ 4
```

### 4. Cycle Graph
- **Vertices connected in a circle**
- **All vertices degree**: 2
- **Forms a closed loop**

```
Cycle Graph:
  0 ─ 1
  │   │
  4 ─ 2
   ╲ ╱
    3
```

## Operations Complexity

| Operation | Time Complexity | Description |
|-----------|----------------|-------------|
| **addEdge(u, v)** | O(1) | Add to end of adjacency lists |
| **removeEdge(u, v)** | O(degree) | Search and remove from lists |
| **hasEdge(u, v)** | O(degree) | Linear search in adjacency list |
| **getNeighbors(v)** | O(1) | Return reference to list |
| **getDegree(v)** | O(1) | Return size of adjacency list |

### Space Complexity
- **Total space**: O(V + 2E) = O(V + E)
- **Each edge stored twice**: Once for each endpoint
- **Vertex storage**: O(V) for the adjacency list vector
- **Edge storage**: O(E) for all edge endpoints

## Key Features

### ✅ Advantages of Adjacency List
- **Space efficient**: O(V + E) vs O(V²) for adjacency matrix
- **Dynamic**: Easy to add/remove vertices and edges
- **Iteration friendly**: Easy to iterate over neighbors
- **Sparse graph optimal**: Excellent for graphs with few edges

### ⚠️ Limitations
- **Edge lookup**: O(degree) time to check edge existence
- **Not cache friendly**: Scattered memory access
- **Duplicate prevention**: Requires checking before adding edges

## Implementation Features

### Error Handling
```cpp
// Vertex validation
if (vertex < 0 || vertex >= numVertices) {
    std::cout << "Error: Invalid vertex" << std::endl;
    return;
}

// Duplicate edge prevention
if (hasEdge(vertex1, vertex2)) {
    std::cout << "Warning: Edge already exists" << std::endl;
    return;
}

// Self-loop prevention  
if (vertex1 == vertex2) {
    std::cout << "Warning: Self-loop ignored" << std::endl;
    return;
}
```

### Utility Functions

## Graph Statistics

### Degree Information
- **Degree of vertex**: Number of edges connected to it
- **Maximum degree**: Highest degree among all vertices
- **Minimum degree**: Lowest degree among all vertices
- **Average degree**: 2E/V (each edge contributes 2 to total degree)

### Graph Properties
- **Dense graph**: Many edges (E ≈ V²)
- **Sparse graph**: Few edges (E ≈ V)
- **Connected graph**: Path exists between any two vertices
- **Complete graph**: Every pair of vertices is connected

## Example Construction

