# Heap Data Structure

## What is a Heap?

A **heap** is a specialized tree-based data structure that satisfies the **heap property**. It's implemented as a **complete binary tree** stored in an array, making it memory-efficient and cache-friendly.

```
              Max-Heap                           Min-Heap
                 50                                 10
               /    \                             /    \
             30      40                         20      30
            /  \    /  \                       /  \    /  \
          10   20  25   35                   40   50  60   70
          
    Parent >= Children              Parent <= Children
```

## Types of Heaps

| Type | Property | Root Element | Common Use |
|------|----------|--------------|------------|
| **Max-Heap** | Parent ≥ Children | Maximum | Priority queues (max first) |
| **Min-Heap** | Parent ≤ Children | Minimum | Dijkstra's algorithm, scheduling |

## Array Representation

A heap is stored in an array with the following index relationships (0-indexed):

```
Array:  [50, 30, 40, 10, 20, 25, 35]
Index:   0   1   2   3   4   5   6

Tree structure:
                    50 (0)
                  /       \
              30 (1)      40 (2)
             /    \      /    \
          10 (3) 20 (4) 25 (5) 35 (6)
```

### Index Formulas

For a node at index `i`:
- **Parent**: `(i - 1) / 2`
- **Left Child**: `2 * i + 1`
- **Right Child**: `2 * i + 2`

```
Example for node at index 1 (value 30):
- Parent: (1-1)/2 = 0  → 50 ✓
- Left:   2*1+1 = 3    → 10 ✓
- Right:  2*1+2 = 4    → 20 ✓
```

## Core Operations

### 1. Insert (Bubble Up / Swim)

Add element at the end, then "bubble up" to restore heap property.

```
Insert 60 into max-heap:

Step 1: Add at end          Step 2: Compare with parent    Step 3: Swap if needed
        50                          50                              60
       /  \                        /  \                            /  \
     30    40                    30    40                        30    50
    /  \  /  \                  /  \  /  \                      /  \  /  \
   10 20 25 [60]               10 20 25 [60]                   10 20 25  40
                                      ↑                         
                               60 > 40? YES, swap!       60 > 50? YES, swap!
```

**Time Complexity**: O(log n) — at most travel up the height of tree

```cpp
void insert(int value) {
    data.push_back(value);      // Add at end
    bubbleUp(data.size() - 1);  // Restore heap property
}

void bubbleUp(int i) {
    while (i > 0 && data[parent(i)] < data[i]) {
        swap(data[parent(i)], data[i]);
        i = parent(i);
    }
}
```

### 2. Extract Max/Min (Bubble Down / Sink)

Remove root, replace with last element, then "bubble down".

```
Extract max from heap:

Step 1: Swap root with last    Step 2: Remove last    Step 3: Bubble down
        50                             10                      40
       /  \                           /  \                    /  \
     40    30        →              40    30      →         10    30
    /                              /
  [10]                            —                          (done - 10 < both children)

Actually step 3 continues:
        40                      
       /  \                     
     10    30                   
       ↓                        
   10 < 40? No, check children  
   Left(none) Right(none) → done
```

Wait, let me show a better example:

```
Extract max from:
        60
       /  \
     50    40
    /  \
   30  20

Step 1: Swap 60 ↔ 20     Step 2: Remove 60     Step 3: Bubble down 20
        20                      20                      50
       /  \                    /  \                    /  \
     50    40       →        50    40       →        20    40
    /  \                    /                       /
   30 [60]                 30                      30
   
                           20 < 50? swap!         20 < 30? swap!
                           
Final:    50
         /  \
       30    40
      /
    20
```

**Time Complexity**: O(log n)

```cpp
int extractMax() {
    int maxVal = data[0];
    data[0] = data.back();  // Replace root with last
    data.pop_back();        // Remove last
    bubbleDown(0);          // Restore heap property
    return maxVal;
}

void bubbleDown(int i) {
    while (true) {
        int largest = i;
        int l = left(i), r = right(i);
        
        if (l < size && data[l] > data[largest]) largest = l;
        if (r < size && data[r] > data[largest]) largest = r;
        
        if (largest == i) break;  // Heap property satisfied
        
        swap(data[i], data[largest]);
        i = largest;
    }
}
```

### 3. Peek

Simply return the root element.

**Time Complexity**: O(1)

```cpp
int peek() {
    return data[0];  // Max for max-heap, min for min-heap
}
```

### 4. Build Heap (Heapify)

Convert an arbitrary array into a heap.

**Naive approach**: Insert elements one by one → O(n log n)

**Optimal approach**: Start from last non-leaf node and bubble down → O(n)

```
Build heap from [3, 1, 6, 5, 2, 4]:

Initial (as tree):
        3
       / \
      1   6
     / \ /
    5  2 4

Start from last non-leaf (index 2, value 6):
- Node 6: children are [4]. 6 > 4 ✓ (no change)

Move to index 1 (value 1):
        3
       / \
     [1]  6        1 < 5? swap!
     / \ /
    5  2 4
    
        3
       / \
      5   6
     / \ /
    1  2 4

Move to index 0 (value 3):
       [3]
       / \         3 < 6? swap!
      5   6
     / \ /
    1  2 4

        6
       / \
      5   3
     / \ /
    1  2 4

Final max-heap: [6, 5, 3, 1, 2, 4]
```

**Why O(n)?** Most nodes are near the bottom and travel very short distances.

```cpp
// Build heap from array
MaxHeap(vector<int>& arr) : data(arr) {
    // Start from last non-leaf node
    for (int i = (size - 1) / 2; i >= 0; i--) {
        bubbleDown(i);
    }
}
```

## Complexity Summary

| Operation | Time Complexity | Space Complexity |
|-----------|----------------|------------------|
| Insert | O(log n) | O(1) |
| Extract Max/Min | O(log n) | O(1) |
| Peek | O(1) | O(1) |
| Build Heap | O(n) | O(1) |
| Search | O(n) | O(1) |

## Heapsort

Use a heap to sort an array in O(n log n):

```cpp
void heapsort(vector<int>& arr) {
    // 1. Build max-heap: O(n)
    for (int i = n/2 - 1; i >= 0; i--)
        heapify(arr, n, i);
    
    // 2. Extract elements one by one: O(n log n)
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);   // Move max to sorted portion
        heapify(arr, i, 0);      // Heapify reduced heap
    }
}
```

## Heap vs Other Data Structures

| Structure | Insert | Delete Max | Find Max | Find Any |
|-----------|--------|------------|----------|----------|
| Unsorted Array | O(1) | O(n) | O(n) | O(n) |
| Sorted Array | O(n) | O(1) | O(1) | O(log n) |
| **Heap** | O(log n) | O(log n) | O(1) | O(n) |
| BST (balanced) | O(log n) | O(log n) | O(log n) | O(log n) |

**When to use a heap**: When you need efficient access to the maximum (or minimum) element with fast insertions, but don't need to search for arbitrary elements.

## Applications

1. **Priority Queues** — Task scheduling, event-driven simulation
2. **Heapsort** — In-place O(n log n) sorting
3. **Graph Algorithms** — Dijkstra's shortest path, Prim's MST
4. **K-th Largest/Smallest** — Keep a heap of size k
5. **Median Maintenance** — Use two heaps (max-heap + min-heap)
6. **Merge K Sorted Lists** — Min-heap of list heads

## Common Patterns

### Pattern 1: K Largest Elements
```cpp
// Use a MIN-heap of size k
// If new element > heap.top(), pop and push
MinHeap heap;
for (int x : stream) {
    heap.push(x);
    if (heap.size() > k) heap.pop();
}
// Heap contains k largest elements
```

### Pattern 2: Running Median (Two Heaps)
```cpp
MaxHeap maxHeap;  // Lower half (max at top)
MinHeap minHeap;  // Upper half (min at top)

void addNum(int num) {
    maxHeap.push(num);
    minHeap.push(maxHeap.top());
    maxHeap.pop();
    
    if (minHeap.size() > maxHeap.size()) {
        maxHeap.push(minHeap.top());
        minHeap.pop();
    }
}

double getMedian() {
    if (maxHeap.size() > minHeap.size())
        return maxHeap.top();
    return (maxHeap.top() + minHeap.top()) / 2.0;
}
```

## C++ STL: priority_queue

```cpp
#include <queue>

// Max-heap (default)
priority_queue<int> maxHeap;
maxHeap.push(10);
maxHeap.push(20);
cout << maxHeap.top();  // 20
maxHeap.pop();

// Min-heap
priority_queue<int, vector<int>, greater<int>> minHeap;
minHeap.push(10);
minHeap.push(5);
cout << minHeap.top();  // 5
```

## Key Insights

1. **Complete binary tree** ensures O(log n) height
2. **Array storage** is memory-efficient (no pointers needed)
3. **Bubble up/down** are the only heap-restoring operations needed
4. **Build heap in O(n)** by working bottom-up
5. **Not suitable for searching** — use BST if you need to find arbitrary elements

## Relationship: Heap vs Priority Queue

- **Heap** is the data structure (how it's organized)
- **Priority Queue** is the abstract data type (what operations it supports)
- A priority queue is commonly *implemented* using a heap

```
Priority Queue (ADT)          Heap (Data Structure)
├── insert(element)     →     uses bubbleUp
├── extractMax()        →     uses bubbleDown  
└── peek()              →     return root
```
