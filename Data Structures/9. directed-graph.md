# 9. Directed Graph Data Structure

## Overview
Implementation of a **directed graph** data structure using **adjacency list representation**. This focuses on the data structure itself, highlighting the key differences from undirected graphs - edges have direction, asymmetric relationships, and specialized vertex properties.

## Key Concepts

### Directed Graph
- A graph where **edges have direction**
- Edge (u,v) goes **from u to v only**
- **Asymmetric relationship**: edge (u,v) ≠ edge (v,u)
- Each edge has a **source** and a **destination**

### Key Differences from Undirected Graphs
- **Directed Edges**: One-way connections only
- **In-degree vs Out-degree**: Separate incoming and outgoing edge counts
- **Asymmetric Adjacency**: u→v doesn't imply v→u
- **Special Vertices**: Sources (in-degree 0), sinks (out-degree 0)

### Adjacency List for Directed Graphs
- **Forward List**: Stores outgoing edges for each vertex
- **Reverse List**: Stores incoming edges (optional, for efficiency)
- **Space Efficient**: O(V + E) storage
- **Asymmetric Storage**: Each edge stored only once

## Data Structure Components

### Core Data Members
```cpp
class DirectedGraph {
private:
    int numVertices;
    std::vector<std::vector<int>> adjacencyList;        // Outgoing edges
    std::vector<std::vector<int>> reverseAdjacencyList; // Incoming edges
};
```

### Key Operations
- **addEdge(u, v)**: Add directed edge from u to v
- **removeEdge(u, v)**: Remove directed edge from u to v
- **hasEdge(u, v)**: Check if directed edge u→v exists
- **getOutgoingNeighbors(v)**: Get vertices that v points to
- **getIncomingNeighbors(v)**: Get vertices that point to v
- **getOutDegree(v)** / **getInDegree(v)**: Count outgoing/incoming edges

## Implementation Details

### Adding a Directed Edge
```cpp
void addEdge(int source, int destination) {
    // Add destination to source's outgoing list
    adjacencyList[source].push_back(destination);
    
    // Add source to destination's incoming list (for efficiency)
    reverseAdjacencyList[destination].push_back(source);
}
```

### Degree Calculations
```cpp
int getOutDegree(int vertex) const {
    return adjacencyList[vertex].size();        // Count outgoing edges
}

int getInDegree(int vertex) const {
    return reverseAdjacencyList[vertex].size(); // Count incoming edges
}

int getTotalDegree(int vertex) const {
    return getInDegree(vertex) + getOutDegree(vertex);
}
```

### Edge Existence Check
```cpp
bool hasEdge(int source, int destination) const {
    return std::find(adjacencyList[source].begin(), 
                    adjacencyList[source].end(), 
                    destination) != adjacencyList[source].end();
}
```

## Memory Layout

### Directed Adjacency Structure
```
Graph with edges: 0→1, 0→2, 1→3, 2→1

Forward Adjacency (Outgoing):      Reverse Adjacency (Incoming):
Vertex 0: [1, 2]                   Vertex 0: []
Vertex 1: [3]                      Vertex 1: [0, 2]  
Vertex 2: [1]                      Vertex 2: [0]
Vertex 3: []                       Vertex 3: [1]
```

### Memory Complexity
- **Space**: O(V + E) for forward + O(V + E) for reverse = O(V + E)
- **Each edge stored once**: Unlike undirected graphs (stored twice)
- **Optional reverse list**: Can omit if only outgoing operations needed

## Vertex Classifications

### 1. **Source Vertices**
- **In-degree = 0, Out-degree > 0**
- No incoming edges, has outgoing edges
- **Starting points** in directed flows

### 2. **Sink Vertices**  
- **Out-degree = 0, In-degree > 0**
- No outgoing edges, has incoming edges
- **Ending points** in directed flows

### 3. **Isolated Vertices**
- **In-degree = 0, Out-degree = 0**
- No connections in either direction
- **Disconnected** from graph

### 4. **Intermediate Vertices**
- **In-degree > 0, Out-degree > 0**
- Both incoming and outgoing edges
- **Transit points** in directed flows

## Common Directed Graph Patterns

### 1. Tournament (Complete Directed Graph)
- **Every pair of vertices has exactly one directed edge**
- **Total edges**: n(n-1)/2 for n vertices
- **Models**: Competition results, preference rankings

```
Tournament with 4 vertices:
0 → 1, 2, 3
1 → 2, 3
2 → 3
```

### 2. Directed Tree (Rooted Tree)
- **One root** with in-degree 0
- **All other vertices** have in-degree 1
- **No cycles**, directed paths from root

```
Rooted Tree:
    0 (root)
   ↙ ↘
  1   2
  ↓   ↓
  3   4
```

### 3. Directed Cycle
- **Vertices connected in circular fashion**
- **Every vertex** has in-degree 1 and out-degree 1
- **Closed loop** with direction

```
Directed Cycle:
0 → 1
↑   ↓
3 ← 2
```

### 4. Directed Acyclic Graph (DAG)
- **No directed cycles**
- **Enables topological ordering**
- **Models**: Dependencies, scheduling, inheritance

```
DAG:
  0
 ↙ ↘
1   2
 ↘ ↙ ↘
  3   4
```

## Operations Complexity

| Operation | Time Complexity | Description |
|-----------|----------------|-------------|
| **addEdge(u, v)** | O(1) | Add to end of adjacency lists |
| **removeEdge(u, v)** | O(out-degree) | Search and remove from outgoing list |
| **hasEdge(u, v)** | O(out-degree) | Linear search in outgoing list |
| **getOutgoingNeighbors(v)** | O(1) | Return reference to outgoing list |
| **getIncomingNeighbors(v)** | O(1) | Return reference to incoming list |
| **getOutDegree(v)** | O(1) | Return size of outgoing list |
| **getInDegree(v)** | O(1) | Return size of incoming list |

### Space Complexity
- **Forward adjacency**: O(V + E)
- **Reverse adjacency**: O(V + E) (optional)
- **Total**: O(V + E) space complexity

## Key Features

### ✅ Advantages of Directed Graphs
- **Models real relationships**: Many real-world connections are one-way
- **Enables algorithms**: Topological sort, strongly connected components
- **Efficient representation**: Each edge stored only once
- **Rich analysis**: In/out degree properties, source/sink identification

### ⚠️ Considerations
- **Asymmetric operations**: Must consider edge direction
- **More complex than undirected**: Additional degree types and vertex classifications
- **Reverse adjacency overhead**: Extra memory if bidirectional queries needed

### Comprehensive Output

## Graph Statistics

### Degree Properties
- **Out-degree sum** = **In-degree sum** = **Total edges**
- **Maximum out-degree**: Highest outgoing connections
- **Maximum in-degree**: Highest incoming connections
- **Degree distribution**: Analysis of connectivity patterns

### Structural Properties
- **Strongly connected**: Every vertex reachable from every other
- **Weakly connected**: Underlying undirected graph is connected
- **Acyclic**: No directed cycles (DAG property)

## Example Construction

### Building a Simple Directed Graph
```cpp
// Create graph with 4 vertices
DirectedGraph graph(4);

// Add directed edges
graph.addEdge(0, 1);  // 0 points to 1
graph.addEdge(1, 2);  // 1 points to 2
graph.addEdge(2, 3);  // 2 points to 3
graph.addEdge(3, 0);  // 3 points to 0 (creates cycle)

// Result: Directed cycle
//   0 → 1
//   ↑   ↓
//   3 ← 2
```
