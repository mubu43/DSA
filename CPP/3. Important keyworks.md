# 1. Object / Class / OOP Keywords

### `this`

**What it is**

* Pointer to the current object

**Why needed**

* Disambiguates member variables
* Enables method chaining

```cpp
class A {
    int x;
public:
    void set(int x) {
        this->x = x;
    }
};
```

---

### `virtual`

**What it is**

* Enables run-time polymorphism

**Why needed**

* Allows derived class functions to be called via base pointer

```cpp
virtual void process();
```

---

### `override`

**What it is**

* Compile-time check that a function overrides a virtual base function

**Why needed**

* Prevents subtle bugs due to signature mismatch

```cpp
void process() override;
```

---

### `final`

**What it is**

* Prevents further overriding or inheritance

**Why needed**

* Performance optimization
* Design intent clarity

```cpp
class Derived final {};
```

---

### `mutable`

**What it is**

* Allows modification inside `const` functions

**Why needed**

* Logical constness (e.g., caching, counters)

```cpp
mutable int cacheHits;
```

---

# 2. Storage Duration / Linkage

### `static`

**Most overloaded keyword in C++**

| Context        | Meaning                   |
| -------------- | ------------------------- |
| Local variable | Lifetime = entire program |
| Global         | Internal linkage          |
| Class member   | Shared among all objects  |

```cpp
static int counter;
```

**Why needed**

* Control lifetime
* Avoid global symbol collisions

---

### `extern`

**What it is**

* Declares a variable/function defined elsewhere

**Why needed**

* Cross-file linking

```cpp
extern int g_counter;
```

---

### `thread_local`

**What it is**

* One instance per thread

**Why needed**

* Thread-safe globals

```cpp
thread_local int tls_id;
```

---

# 3. Constness & Type Safety

### `const`

**What it is**

* Prevents modification

**Why needed**

* Compiler enforcement
* Self-documenting APIs

```cpp
void f(const int* p);
```

---

### `constexpr`

**What it is**

* Compile-time evaluation

**Why needed**

* Performance
* Safer macros replacement

```cpp
constexpr int size = 128;
```

---

### `volatile`

**What it is**

* Prevents compiler optimization on variable access

**Why needed**

* Memory-mapped I/O
* Hardware registers

```cpp
volatile int status;
```

❌ **Not for thread synchronization**

---

# 4. Function & Performance Keywords

### `inline`

**What it is**

* Suggests function body replacement at call site

**Why needed**

* Reduce function call overhead
* Header-only functions

```cpp
inline int add(int a, int b);
```

---

### `noexcept`

**What it is**

* Declares function will not throw

**Why needed**

* STL move optimizations
* Program correctness

```cpp
void f() noexcept;
```

---

### `explicit`

**What it is**

* Prevents implicit conversions

**Why needed**

* Avoid accidental object creation

```cpp
explicit MyClass(int x);
```

---

# 5. Memory & Ownership

### `new` / `delete`

**What they do**

* Dynamic memory allocation

**Why needed**

* Heap management

```cpp
int* p = new int(10);
delete p;
```

(Prefer smart pointers)

---

### `sizeof`

**What it does**

* Compile-time size calculation

```cpp
sizeof(int);
```

---

### `alignas` / `alignof`

**What it does**

* Control memory alignment

**Why needed**

* SIMD, cache alignment

```cpp
alignas(64) char buffer[64];
```

---

# 6. Templates & Generic Programming

### `template`

**What it is**

* Compile-time polymorphism

```cpp
template <typename T>
```

---

### `typename`

**What it is**

* Disambiguates dependent types

**Why needed**

* Required by compiler in templates

```cpp
typename T::value_type;
```

---

### `auto`

**What it is**

* Type deduction

**Why needed**

* Reduces verbosity
* Prevents type mismatch

```cpp
auto x = 10;
```

---

# 8. C++11+ Move & Value Categories

### `&&`

**What it is**

* Rvalue reference

**Why needed**

* Move semantics
* Perfect forwarding

```cpp
T&& value;
```

---

### `std::move`

**What it does**

* Casts to rvalue

```cpp
std::move(obj);
```

---

# 9. Concurrency

### `atomic`

**What it is**

* Lock-free synchronization primitive

```cpp
std::atomic<int> counter;
```

---

### `mutable` + atomics

Used together for thread-safe statistics

# 10. C-Specific but Still Important

### `restrict` (C)

**What it is**

* No pointer aliasing

**Why needed**

* Optimization

```c
int* restrict p;
```
