## Core Idea of Templates (1-minute intuition)

A **template** lets you write code **once**, and the compiler **generates type-specific versions** for you.

> Think of a template as a **code blueprint**, not runtime polymorphism.

---

## Example 1: A Generic Function Operating on `std::vector<T>`

Let’s write a function that **prints elements of a vector**, regardless of type.

### Template function

```cpp
#include <iostream>
#include <vector>
#include <string>

template <typename T>
void printVector(const std::vector<T>& vec) {
    for (const T& elem : vec) {
        std::cout << elem << " ";
    }
    std::cout << "\n";
}
```

### Usage with `int` and `std::string`

```cpp
int main() {
    std::vector<int> numbers = {1, 2, 3, 4};
    std::vector<std::string> names = {"Alice", "Bob", "Charlie"};

    printVector(numbers);  // T = int
    printVector(names);    // T = std::string
}
```

### What the compiler does (conceptually)

```cpp
void printVector(const std::vector<int>&);
void printVector(const std::vector<std::string>&);
```

## Example 2: Template Function That Performs an Operation

Let’s write a function that **returns the sum / concatenation** of elements.

```cpp
template <typename T>
T accumulateVector(const std::vector<T>& vec) {
    T result{};  // default initialization

    for (const T& elem : vec) {
        result += elem;
    }
    return result;
}
```

### Usage

```cpp
int main() {
    std::vector<int> nums = {1, 2, 3};
    std::vector<std::string> words = {"Hello ", "World"};

    std::cout << accumulateVector(nums) << "\n";     // 6
    std::cout << accumulateVector(words) << "\n";    // Hello World
}
```

### Why this works

* `int` supports `+=`
* `std::string` supports `+=`

Templates rely on **what operations a type supports**, not inheritance
(this is called **duck typing at compile time**).

## Example 3: Template Class Using `std::vector<T>`

```cpp
template <typename T>
class Container {
public:
    void add(const T& value) {
        data_.push_back(value);
    }

    void print() const {
        for (const auto& v : data_) {
            std::cout << v << " ";
        }
        std::cout << "\n";
    }

private:
    std::vector<T> data_;
};
```

### Usage

```cpp
int main() {
    Container<int> intContainer;
    intContainer.add(10);
    intContainer.add(20);

    Container<std::string> stringContainer;
    stringContainer.add("foo");
    stringContainer.add("bar");

    intContainer.print();
    stringContainer.print();
}
```

## Templates vs Inheritance (Interview Favorite)

| Templates    | Inheritance            |
| ------------ | ---------------------- |
| Compile-time | Runtime                |
| Faster       | Virtual dispatch       |
| Type-safe    | Base-class constrained |
| No vtable    | vtable overhead        |
